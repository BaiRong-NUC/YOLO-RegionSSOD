# 第一篇论文：实验缺口与低成本推进清单

> 建立日期：2026-10-30；对象为第一篇“面向区域局部标注的尺度可靠性航拍小目标半监督检测方法”。
> 当前状态是投稿前规划：现有两 seed 结果可支撑阶段性方法结论，不能仅据此声称满足北核录用、
> 跨 split/教师泛化、官方 AP_small 或统计显著性。原 Gate 3 未达的历史判定保留。

## 1. 现有证据与文章最小闭环

已有：固定 VisDrone split seed0、固定 B1 教师、10% 区域面积、YOLO11s、学生 30 epoch、
完整 548 图 val960 的 B1/B2/P1 seed0 对照；B2/P1 学生 seed0/1 配对；
尺度阈值 seed0/1 重复；no-ignore 单因素对照；四类成功/失败案例；逐尺寸与逐类别结果。
P1−B2 两学生 seed 的 mAP50-95 为 +0.2893±0.0644 pp，small recall 为
+1.7854±0.1304 pp；large recall 方向不一致。现有表 4-1 至 4-6 仍为 seed0 主表，
表 4-S3/S4 单列重复结果。

| 问题 | 现有回答 | 文章仍缺的证明 |
|---|---|---|
| 如何定义区域局部标注 | 每图一个目标中心 tile、一个低重叠未标注 tile；隐藏 GT 仅诊断 | 协议复现和 train/val 隔离已具备，外推需外部数据才成立 |
| 半监督是否有效 | B2 相对 B1 mAP50-95 +0.542 pp | 正式训练预算与至少两 seed 的完整 B1 对照可加强；现有 seed0 不足以作稳定性结论 |
| 尺度阈值是否有效 | 两 seed 同向；统一阈值 mAP50-95 更低 | 已有 targeted ablation，足以作为机制证据之一，但不是全部组合贡献 |
| uncertain-ignore 是否有效 | 单 seed 全量对照整体 mAP 近似持平、small recall 下降 | 不能把组合增益归因于 ignore；需如实写成边界，不能另造正向结论 |
| 软权重是否有效 | 已核实全量 no-soft 的训练/val/recall/派发均不存在；仅有 1024 图×5 epoch 中性筛查 | 短程筛选不进入主表；只有完整 30 epoch、同数据/参数及完整验证可作正式消融 |
| 方法贡献边界 | 最直接相关工作 S³OD 已含尺度阈值和教师负样本处理 | 不能声称“首次”；需要清楚写成区域协议下的问题、可靠监督组合及诊断证据 |
| 验证泛化和强度 | 单一 split、固定教师和 30 epoch；Ultralytics 开发指标 | 投稿层次与学校要求取决于正式实验、重复 split/教师及官方评测是否必要 |

期刊稿件不需要把所有可能实验都做一遍，但必须让主张与证据厚度一致。
如果时间是当前主要约束，可优先争取“单 split、固定教师、两学生 seed”的完整方法稿；
新 split、独立教师和正式 100 epoch 矩阵是否追加，应按导师/期刊反馈决定。
不能用未做实验的预期结果补足主张。

## 2. 零训练优先：已完成漏检诊断（2026-10-30）

新增 `scripts/audit_paper1_gaps.py`，只读取冻结教师候选、P1 伪标签、区域清单和训练集隐藏 GT；
隐藏 GT 不写回训练标签。对 6,471 个未标注 tile 的 38,245 个可见 GT 进行与原文一致的
类别一致、IoU≥0.50、稳定 IoU 降序一对一匹配，精确重放 P1 的 35,067 个正伪标签和
25,669 个真匹配。工具复核 11,319 个来源哈希及固定计数，必要时可 `--check` 复现。

| 未匹配 hidden GT 证据类别（互斥，按顺序归类） | all 12,576 | small 8,984 |
|---|---:|---:|
| 同类别 positive 候选竞争但未匹配 | 208 | 172 |
| 同类别 ignore 候选 IoU≥0.50（可能受一对一竞争影响） | 5,416 | 3,652 |
| 异类别候选 IoU≥0.50（类别不符） | 2,750 | 1,644 |
| 同类别候选 IoU 0.10–0.50（定位/形状近似但未达阈） | 1,513 | 1,243 |
| 异类别候选 IoU 0.10–0.50 | 809 | 676 |
| 无保存 candidate IoU≥0.10（候选缺口） | 1,880 | 1,597 |

这些是**描述性证据类别**，不是已经证实的因果阶段。`ignore_same_class` 不保证框可独立转正；
同一 GT 可能被已匹配或正候选占用。`no_saved_candidate` 也不能区分真实未预测、低于 0.05、被 NMS 删、
max_det 截断；现有 `candidates.jsonl` 已是 NMS 后产物。候选缺口多不自动证明“漏检测重新生成训练”
有效，类别不符多也不自动证明“分类损失更好”。

P1 的 0.30≤conf<0.50 small positive 有 7,400 个框，在完整 P1 联合匹配中有
3,165 个 matched predictions，precision 为 42.77%。这是 P1 内部条件统计，不是它们
相对 B2 新增独立检出的比例；也不能与恢复分析中“锁定旧匹配后新增匹配/额外框”直接混用。

随后已完成 [ignore 可恢复增量分析](paper/ignore_recovery_analysis.md)：入训 ignore 的
普通一对一新增匹配 5,303、条件最大基数上界 5,315，新增 small 3,627；若直接保留全部
52,117 框，新增独立匹配比例仅 10.18%。仅放宽 small 到 0.25 时也只有 27.12%。
因此存在覆盖空间，但尚无值得扩训的可靠转正规则；下一步先验证无 GT 的可靠性线索。

## 3. 推荐的低成本实验阶梯

### L0：零训练复核（已做部分及下一步）

1. **已完成**：用冻结 P1 候选做可恢复增量分析：同一类别、IoU≥0.50 的 ignore 框，是否与一个已匹配正框重复，
   或代表不同 GT；在保持一对一分配的模拟中，以现有框集合直接转正可新增多少匹配。此分析显示上限，
   不能当作实际新算法成绩。
2. 比较新加候选的路径：用教师权重在少量保留的 source tiles 上以 NMS IoU 稍高、max_det 略高重跑。
   先做候选覆盖 + 速度/显存测量，不训练学生。样本数应先从 64–128 tile 起，根据增加候选量再决定是否扩展。
   该推理不能与已有验证预测混淆，也不能用隐藏 GT 调训练。
3. **已核实**：软权重完整30epoch产物不存在，5epoch筛查中性。用户随后允许至多30epoch
   自主小试并收束到A；现选择仅补这一组正式单因素消融，见第7节。
   这是为检验机制填补证据缺口，不代表旧筛选已过线，不重复5epoch筛查。
4. 复核 no-ignore 与主 P1 的逐类/尺寸错误计数及置信区间，确保“ignore 不必然提升整体 mAP”如实写入。

**L0停止规则：**候选覆盖增加微乎其微，或可恢复匹配只在重复框上出现，就不进入 L1 训练。

### L1：有界训练筛选（仅在 L0 有显著信号后）

一次只验证一个主机制，且先选从 L0 数据得到的候选：

- 如果主要是 NMS/候选保留导致缺口：只改推断候选保留或空间支持策略，固定其余训练和伪标签判定，
  用相同随机子集训练两臂；不能用验证 GT 产生伪标签。
- 如果 ignore 重叠有明显的可恢复增量：只改 uncertain 候选中可恢复正框的判定，不能改变已有正样本或引入 GT。
- 只有软权重完整对照确属未完成且两 seed 数据仍显示方向性时，才考虑先做现有 1024 图 5 epoch 配对筛选；
  短程结果仅作选择，不能直接进主表。

训练预算建议沿用已有的保守筛选：同一冻结数据子集，双臂 5 epoch、相同随机初始化/增强，完整 val960；
超过一次单因素筛选不再是“低成本探索”。当前没有新训练在跑。

**L1候选线：**相对完整 P1，mAP50-95 至少 +0.3 pp 且 small recall 同向增加，或 small recall 至少 +1.0 pp
且总体不明显下降。此线是停止/继续筛选的工程门槛，不是论文显著性门槛、不是学校要求、
也不是相对 B2 的最终效应量。

### L2：有条件正式确认

只有 L1 过线，才补完整 10% 数据、30 epoch、seed0/1 的配对确认，并做实际参数、连续 epoch、
完整 val960、固定 recall 和保存预测 GT 重放。未过线则停止该机制，保留已有 P1 和诊断结果，
不堆叠模块。L2 训练开始前会另给配置、预算、验收命令和最大并发数，由用户执行。

## 4. 必要但不是最便宜的投稿补强

| 优先级 | 缺口 | 为什么需要 | 采取条件 |
|---|---|---|---|
| P0 稿件可写 | 核对 full-soft-weight 状态；整合失败证据、精度—覆盖与参数成本 | 防止把短程或负面消融误写为正式结果 | L0 完成 |
| P1 方法证据 | 一个可过 L1 的完整单因素机制确认 | 回答“哪一部分造成 P1 增益” | 只有 L1 有同向信号 |
| P1 公平验证 | B1/B2/P1 在正式训练预算上的第二个学生 seed；若预算许可再补 B0 | B1 与 P1 的多 seed 比较、完整监督参考 | 优先于无关模块 |
| P2 泛化证据 | 新的 split seed + 独立教师/伪标签，或 5%/20% 区域面积点 | 检验是否只在当前 split/预算工作 | 期刊/导师要求或方法稿站稳后 |
| P3 外部确认 | 类别映射/协议审计后的 UAVDT 等 | 证明域外迁移 | 只做一次冻结后确认，不反复看测试集 |
| P3 官方评测 | 固定协议下的 VisDrone AP/AP_small/AR500 | 回答开发指标不能回答的问题 | 有可靠官方工具/服务器且训练冻结 |

B0 目前没有正式训练产物，不能写成已有结果。正式 100 epoch 矩阵约需大量 GPU 小时，
在本机约数周的量级；它不是 L0/L1 之前应立即启动的任务。

## 5. 当前建议执行顺序

1. 当前目标只做A第一篇；ignore增量、翻转、NMS/max-det及跨尺度支持检查均完成，
   跨尺度探索后固定候选的256tile不重叠确认未通过，不据此启动训练；
   详见`paper/{cross_view_flip_analysis,candidate_retention_analysis,scale_support_analysis}.md`。
2. 放宽 NMS 新增 210 个正框但仅有 9 个新增独立匹配，提高 max-det 没有新增；
   该路线未达到继续条件，不自动重复调参、全量推理或学生训练。
3. 下一步核对A稿件的结论与最小必要实验清单，一次只决定一项有界验证。
   软权重正式消融、B0、B1重复和正式矩阵继续登记为待补，不自动一次启动全部；
   不把已有中性筛查写成已完成消融，不继续横向扩展新教师或B类补全机制。
4. 用户最新授权允许可靠信号出现后自主进行至多 30 epoch 的小规模训练，
   不是 30 组独立运行；可按预算先筛选，再决定是否做配对确认。
5. 实际启动训练时创建临时进度心跳，在完成、失败或需处理时通知并清理；
   每轮修改中文 Git 提交。更长训练仍须结果支持，原 Gate 3 不变。

本阶段另完成跨尺度探索/确认各256tile的640视图推理，未启动学生训练或生成训练标签。
C/B及树莓派部署均不属于当前执行目标。

## 7. 本轮唯一训练：软权重正式单因素消融

2026-10-30，按用户最新“当前只做A”和至多30epoch的授权，先补当前稿件中唯一
尚无完整对照的软权重开关。此前5epoch中性筛查的结论保留；这次不以预期增益
为理由扩训，而是确定该机制应保留、删去或如实表述为未获支持。

- 新增预算：仅一组、全部11310 tile、30epoch，预计学生约2小时；复用完整P1
  seed0已完成的配对参考，不重新训练参考组。耗时以实际CSV为准，不保证完成时刻。
- 固定原split seed0、B1教师、伪标签、COCO初始化、640/batch8/SGD、增强及
  close_mosaic=10；只把`soft_weights`改为false，ignore保持true。
- 完成后必须验收连续30epoch、全部冻结输入、实际参数、完整548图val960、
  同操作点分尺寸recall和保存预测重放；不把训练中的640验证当作完整val960结果。
- 去软权重相对完整P1的探索性后续线为：mAP50-95≥+0.3pp且small recall不降，
  或small recall≥+1.0pp且mAP50-95不低于−0.1pp。该线在本组训练前记录，
  不替代原Gate3，不表示显著性；达到后也只准备下一步，不自动启动100epoch。
- 若完整P1明显更好，则保留相反方向的机制证据；若近似持平则如实报告中性，
  不为了正向数字追加同参数新种子或改阈值。
- 运行入口：`python -u scripts/run_p1_no_soft_weights.py`；验收入口：
  `python scripts/audit_p1_no_soft_weights.py`。后台包装保存父/子PID、stdout/stderr、
  结束码；不自动重启，不拼接中断epoch。
- 实际启动后创建临时心跳检查活进程、CSV和阶段；完成/失败后清理监控。
  大规模训练仍由用户运行，当前不启动B/C、蒸馏、剪枝或大模型微调。

## 6. 证据与边界

- 论文现状：`docs/paper/{methods,experiments,results_tables,evidence,case_studies}.md`。
- 已验收结果：`outputs/b2_pilot30_s1/{comparison,acceptance_audit,independent_audit}.json`；
