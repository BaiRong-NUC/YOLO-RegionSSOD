# 8 周实验计划

## 1. 论文定位

建议题目：

**面向高分辨率航拍图像的区域局部标注小目标半监督检测方法**

问题不是普通的“少量图片半监督”，而是每张高分辨率图仅标注有限区域。这样
更贴近航拍数据实际标注流程，也能和已有图像级 SSOD、点监督、旋转框稀疏标注
工作形成清楚区别。

论文贡献控制在三点：

1. 建立区域局部标注下的高分辨率航拍小目标检测协议，并公开固定 split。
2. 提出 tile-aware 自训练和尺度感知伪标签筛选。
3. 将低置信度教师预测作为未知区域而不是背景，降低小目标伪标签漏检造成的
   负样本污染，并给出按尺寸、密度和类别的分析。

不要在论文中使用“首次”表述。点监督和稀疏标注已有大量工作，必须依靠具体
问题设定、机制和实验闭环建立差异。

## 2. 固定因素

主实验固定以下因素：

- 检测器：YOLO11s。
- 初始化：COCO 预训练 `yolo11s.pt`。
- 训练输入：640。
- 主评估输入：完整原图，960。
- 优化器：SGD，`lr0=0.01`，`lrf=0.01`。
- 训练轮数：100。
- batch：8；OOM 时所有对照统一降低。
- `close_mosaic=10`，`patience=0`。
- workers：0，先保证 Windows 可复现。
- 数据：VisDrone train/val；最终只补一个外部确认集，不更换主数据集。

主结果阶段不修改 backbone、neck、head、P2、注意力或损失权重。

## 3. 数据协议

### 3.1 标注区域

每张训练图保留一个目标中心 square tile。tile 先随机选择一个真实目标作为锚点，
再加入最大为 tile 边长 20% 的抖动。框与 tile 的可见面积比例低于 0.35 时丢弃。

标注面积比例：

- 5%：主要验证极低标注预算。
- 10%：主结果和主统计检验。
- 20%：较宽松预算，检验方法是否仍有收益。

tile 边长按 `sqrt(area_ratio * image_width * image_height)` 计算。因为原图长宽
不完全一致，实际面积比例会略偏离目标值，`manifest.jsonl` 会逐图记录。

### 3.2 未标注区域

每个训练图额外采样一个随机 tile，默认尽量与标注 tile 的交并比不超过 0.2。
这些 tile 没有监督标签，不能作为纯背景训练。`manifest.jsonl` 记录其中实际可见
的隐藏 GT 数，用于分析教师漏检率。

### 3.3 数据隔离

- 开发与筛选仅使用 VisDrone val。
- 现有 test-dev 已被旧项目反复使用，不作为新论文的盲测证据。
- 最终外部确认优先选择 UAVDT；若车辆类别映射不稳定，则只报告 VisDrone val
  和一次冻结后的官方评估，不虚构“盲测”。
- 标注 split 生成 seed 与训练 seed 必须成对记录。

## 4. Baseline

### B0 Full-supervised reference

完整 VisDrone 标签训练。优先复用旧仓库三 seed 的 YOLO11s 640/100 epoch 结果，
但必须在新仓库记录权重、配置和评估版本。该结果只作为性能上界。

### B1 Partial-supervised crop

只训练标注 tile。它回答“直接丢掉未标注区域会损失多少”。所有后续方法都必须
与它使用同一标注 tile、同一模型和同一训练轮数。

### B2 Naive self-training

用 B1 教师对未标注 tile 做全局阈值 0.50 推理，保留有检测结果的 tile，再与
标注 tile 联合重训一次。它是判断问题是否值得继续的最重要基线。

seed0 的 pilot 固定已完成的 B1 100 epoch `best.pt` 为教师，B2 和后续 P1 共用；
B1/B2 学生各自从 COCO 预训练独立训练 30 epoch，按完整原图 960 指标比较。
教师训练成本单独记录；不能用 B1 100 epoch 结果或该 run 的第 30 行 CSV 代替
独立 30 epoch B1 学生。具体命令见 `docs/baseline_protocol.md` 第 4.1 节。

### P1 Scale-aware self-training

2026-10-27 已完成工程实现及 30 epoch 配对验收，整体 mAP 与小目标 recall
均有初步收益；原 Gate 3 未达 +0.5 个百分点门槛。用户当前优先整理已有成果，
具体结果和后续决策见 `paper_completion_plan.md` 第 3.8 节。第一版固定参数见
`configs/pseudo_p1_10.yaml`，执行路径和损失语义见 baseline 协议第 4.3 节：

- 小、中、大目标使用不同伪标签置信阈值。
- 伪标签分类损失按教师置信度加权，而不是全部硬标签等权。
- 低于伪标签正阈值但高于下限的候选框，不作为背景负样本。
- 记录每尺寸的伪标签 precision/recall 和覆盖量。

P1 先做一轮离线自训练。只有 P1 明显优于 B2 后，才增加第二轮或在线 EMA 教师。

## 7. 消融

只保留能回答论文核心问题的消融：

1. 全局阈值 vs 尺度分层阈值。
2. 有/无低置信度 uncertain-ignore。
3. 有/无置信度软权重。
4. 一轮 vs 两轮自训练。
5. 未标注 tile 数 1 vs 2，仅在 10% 标签 seed 0 上做。

局部密度分支只有在第 3 周 pilot 已显示独立信号时才加入；不要为了“模块数量”
临时增加分支。

## 8. 指标和统计

主指标：

- mAP50-95。
- mAP50。
- AP_small/tiny，按统一尺寸映射。
- AR500。

分析指标：

- 按尺寸分层的伪标签 precision、recall 和覆盖率。
- 每类 AP，重点观察 bicycle、bus、awning-tricycle 等稀有类。
- 未标注 tile 的隐藏 GT 数与学生误报数。
- 参数量、FLOPs、FPS，确认没有引入不可接受的推理成本。

报告方式：

- 均值 ± 标准差。
- 同一 split 上进行配对比较。
- 预注册主结论：10% 标注面积下，主方法相对 B2 至少 `+1.0 mAP50-95` 或
  `+1.5 AP_small`，且两个 seed 方向一致。
- 低于该效应量时，不把 0.1–0.3 个点的波动写成“显著提升”。

## 9. Go/No-Go 门槛

### Gate 1：工程可复现

20 张图的 split 生成、5 epoch 训练、完整 val 推理均成功；同 seed 生成结果一致。

### Gate 2：半监督信号存在

10% 标签、30 epoch pilot 中，B2 相对 B1 不得低于 `-0.2 mAP50-95`。若下降，
先检查教师伪标签 recall，而不是继续加模块。

### Gate 3：主方法有独立收益

30 epoch pilot 中，P1 相对 B2 至少 `+0.5 mAP50-95`，且 AP_small 或小目标 recall
同向改善。没有达到时停止扩训。

### Gate 4：完整训练可成立

100 epoch 主实验在 10% 标签、两个 seed 上均值相对 B2 达到预注册效应量。
若未达到，把论文改为区域标注失效分析或更换伪标签机制，不叠加更多模块。

## 10. 论文实验章节结构

1. 区域局部标注协议和隐藏 GT 统计。
2. 与 B1/B2 的比较。
3. 5%/10%/20% 标注预算曲线。
4. 尺度阈值、uncertain-ignore、软权重和自训练轮数消融。
5. 伪标签质量与漏检分析。
6. 外部确认和复杂度。

## 11. 风险与退出条件

- B2 完全无收益：优先检查未标注 tile 的实际目标密度、教师阈值和伪标签覆盖。
- P1 的收益只来自更多伪标签数量：必须补 precision 和 AP 分尺寸分析。
- 结果只在 10% 标签出现：检查 5%/20% 曲线，不把它写成全预算稳定提升。
- 稀有类 AP 波动过大：报告实例数，不以单类 0.1 点作为主结论。
- 显存不足：固定降低 batch，不单独给主方法增加梯度累积而不给 baseline。
- 第 6 周仍未过 Gate 4：停止扩训，转为诊断论文或更换单一主机制。
