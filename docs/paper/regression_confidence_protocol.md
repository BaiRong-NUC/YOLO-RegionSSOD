# 伪框回归置信度分配：零推理缓存诊断协议

2026-10-31，计算本项加权质量统计前登记。NWD30轮与两项分配候选的负面记录保留，
本项不继续修改它们。当前P1只对分类乘教师置信度，box/DFL不额外乘置信度。

## 1. 固定单因素

候选仅对已接受正伪框的box与DFL监督乘其原教师前景置信度c；
人工框仍为1，原未加权TAL分母不变，避免归一化抵销。
分类、ignore、分配、标签坐标/数量、入训tile、教师及模型结构保持不变。
权重直接为原c，不拟合校准映射，不设新置信度阈值或幂指数，不按隐藏GT选择框。

分类分数不等同于定位可靠性，本候选不称RUPL、Listen2Student或Soft Teacher
定位抖动筛选的复现，也不把已有置信度加权思想称为首次提出。
这里只问已有c是否足以使回归监督更多落在几何/类别较可靠的现有伪框上，
进而值得做受控30轮学生试验。

## 2. 数据与统计

复用`outputs/positive_localization_20261030/diagnostics.jsonl`的两个不重叠
基础tile组及2710个已接受正伪框，原样保留，没有新增推理、训练或GT匹配。
这些组此前用于其他诊断，是已使用的开发样本，不称新盲测确认。
隐藏GT仅已缓存为诊断质量，不导出标签、拟合权重或改变c。
原质量来源哈希和`audit_positive_localization.py --check`可重放。

对每组small正伪框比较普通均值与按c加权均值：
同类最近GT IoU、IoU≥0.75比例、一对一IoU≥0.50匹配率、Kish有效样本量。
最近GT可重复使用，IoU≥0.75比例不是伪标签precision。
再按类别分别计算IoU均值差，使用原类别数量加权，控制类别组成变化。
同时报告全尺度/各尺度，不只挑有利small指标。

## 3. 固定诊断继续线

两组分别均需满足：

- small至少300框，Kish有效样本量至少为原框数75%；
- c加权同类最近GT IoU均值至少提高0.02；
- c加权IoU≥0.75比例至少提高2个百分点；
- c加权一对一IoU≥0.50匹配率不下降；
- 至少3个类别各有30个small框；在这些类别内控制组成后的平均IoU提高至少0.01。

未通过不修改幂指数、阈值或改选样本追试。通过也不表示学生性能改善，
只是支持准备唯一全量30轮、同seed的单因素学生确认。
权重降低伪框监督总量，本轮若取得收益不能直接归因于逐框可靠性，
后续正式主张需要常数衰减对照区分整体伪监督强度和置信度排序。
性能继续线仍需在训练前固定，不用诊断GT代替val960。
