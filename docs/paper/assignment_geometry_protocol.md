# 检测点与小框回归支持域：零训练诊断协议

2026-10-31，在新增数据推理和诊断结果未知时登记。上一项小框NWD完整30轮
未达到继续线。本项只分析原完整P1的标签分配，不改动其源码、模型或训练产物。

## 1. 实现问题与单因素假设

当前本机Ultralytics 8.4.172的TAL将GT的短边扩至stride[1]=16像素，
再检查点是否在扩大的框内；原GT坐标不改。DFL使用相对anchor的ltrb距离，
负距离会截断。因此候选池中的点可能位于原框外，不能以非负ltrb精确表示原框。
这不是已确认的程序bug：扩大候选池可能有利于小目标覆盖，净效果必须测量。
也不能再以“原实现未处理tiny无点问题”为由提出同样的扩大操作。

唯一候选规则：**原框内存在点时仅使用原框内点；原框内没有点时沿用现有扩框池。**
topk、alpha/beta、IoU计算、冲突处理、目标分数归一化、回归目标和损失均不改。
本诊断对候选规则只做同预测的重分配，不训练、不生成新伪标签。

FCOS原文1904.01355第2.1节式1以框内点到四边的距离作为回归目标；
它是几何定义的来源，不证明本候选优于现有TAL。
RFLA的MCP检索只确认题名/DOI，尚未读其全文，不按题名推断其算法或效果。
最近S³OD已有尺度分配机制；本候选不称首次或其SLA复现。

## 2. 固定样本与计算预算

- 只读取完整11310tile的P1训练集及其开放标签、既有伪标签/ignore。
  不读取隐藏GT、val或test标签，不按检测结果选样。
- 对训练图路径排序后，以NumPy default_rng(20261031)无放回抽256个索引；
  前128为探索、后128为确认，均在首次计算前写入receipt。
  这是基础tile不重复，mosaic可能引用相同来源，不宣称独立来源确认。
- 采用原640训练增强和seed20261031+样本顺序；从同一完整数据集取mosaic，
  不减少参考训练集。记录增强后的正框、置信度和输入张量哈希。
- 只使用已验收完整P1 seed0 best.pt，eval模式固定BN，原始检测头输出，
  FP32，无梯度/优化器更新；最多256个增强输入的前向，不训练或新做val。
  同一原始预测分别计算现有TAL和候选TAL；分配在CPU FP32计算以支持精确重放。
- 保存原始预测、GT、点坐标及有效框mask的压缩缓存、逐目标统计、
  checkpoint/输入/库源码/协议/执行代码SHA256，检查时不重复推理。
  注意训练期AMP和模型演化未由该单checkpoint诊断覆盖。

## 3. 诊断继续条件

只问该机制是否有足够作用空间且没有明显破坏已有覆盖，不以此认定学生性能提升。
探索和确认分别都需满足以下预先固定条件：

1. 基线有有效正分配（目标分数>0）的small框至少100个。
2. 至少50个small框含原框外的有效正分配，且框外分配占small目标分数质量至少1%。
3. 候选使small框外分配的目标分数质量降低至少50%。
4. 候选保留至少99%的基线有效分配目标，分别核对small和全部尺度。
5. 候选的small目标分数质量不少于基线90%，避免仅丢掉绝大多数监督。

small按增强后640像素空间面积<32²定义；有效分配按TAL目标分数>0定义，
不能只用fg_mask计数。mosaic会混合来源，确认组不是独立统计检验。
若条件不足，记录不足且不修改阈值追试；若通过，只支持另登记完整30轮单因素
学生确认。最少30轮性能要求不由本诊断替代，不自动启动100轮或添加其他模块。
