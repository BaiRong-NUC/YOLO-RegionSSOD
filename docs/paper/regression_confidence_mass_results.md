## 为什么不能把它写成实际损失降幅

设正anchor原TAL质量权重为q，框误差项为l，人工框权重为1，
伪框权重为原c，分母D保持原未加权target_scores总和并至少为1，
则某一回归项的形式为：

```text
L = [sum_human(q * l) + sum_pseudo(q * c * l)] / D
```

本项统计sum_box(c)，没有计算每框的正anchor数、q或l，
也没有模拟mosaic后框保留/裁剪及其尺度变化。因此0.670235只表示
“单位框权重”下的平均保留比例，不能写成实际box/DFL损失降低32.98%，
更不能外推为实际梯度减少相同百分比或recall变化。
sum(c)归一化的small份额下降7.4644pp同样只是框级代理。

若30轮过线，仍需区分总伪监督衰减、置信度排序及尺度/类别组成三种解释。
用全量平均c作为常数最多匹配框级权重和，不能直接称“实际监督量匹配”；
未来对照须另行预登记匹配口径，不从本结果拟合指数或尺度补偿。
