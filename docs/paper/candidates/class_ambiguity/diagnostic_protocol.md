# 类别歧义增量信号：零训练诊断协议 v1

2026-11-02，读取新类别分数结果前冻结。研究问题：
在原P1接受规则下，教师top2/top1是否提供超出top1置信度、预测尺度和类别的错误类别信息？
本轮只做教师前向与统计，不训练学生、不修改原伪标签。

## 固定样本及身份验证

- 固定随机seed20261102，从6471训练原图无放回抽512张，前256设计、后256确认；
  按原图隔离，只读取其原有labeled tile标签。教师曾训练过这些可见区域，
  因此这是教师训练域内确认，不是假装教师未见的外部验证。
- 从原6471未标注tile预测清单的完整8图batch中，以seed20261103抽16组（128图）。
  只检查完整类别分数、原候选身份和信号分布，不读取其隐藏GT。
- 固定原B1 best.pt、Ultralytics8.4.172、960、batch8、FP32、NMS0.7、
  conf0.05、max_det500、原ScalePolicy。
- 使用NMS返回原anchor索引，精确提取10类sigmoid分数；逐batch与不返回索引的
  原NMS输出torch.equal。分数不得归一化为softmax后再用于此诊断。
- 未标注样本保持原完整batch和顺序，按候选行顺序对照旧candidates.jsonl；
  类别、状态、数量必须相同，conf/归一化框最大差≤1e-6。
  不允许最近框替换身份。若未通过，不连接原伪标签，不给训练入口。

## 分析单位、信号及模型

只分析按原ScalePolicy会成为positive的预测。用可见区域GT在原tile坐标评价。
class-agnostic最大IoU≥0.50称几何可对应；若同一预测以IoU≥0.50同时对应不同GT类别，
记为几何/类别歧义并从主要类别错误分析排除，数量另报。
主终点y=该几何对应类别与预测top1不一致。多个预测可指向同一个目标；
这不是独立目标召回/检测precision，bootstrap以原图为单位。
同时报告所有接受框的同类IoU达标率和背景/定位失败，不仅选择主终点。

原始信号r=p2/p1（p1为最大分数、p2为第二大分数）。预定high=r≥0.25、
low=r<0.10、中间组均完整报告；不是训练阈值。
baseline逻辑回归特征：截距、logit(p1)、log(原tile预测面积)、预测类别1–9指示。
candidate只加r，特征按设计集均值/标准差标准化；截距不正则，其他系数L2=1。
固定IRLS最多80次，不按确认集选特征、惩罚或阈值。
设计集拟合后只在256确认图算log-loss、Brier和AUROC。

## 结果出现前的继续条件

以下全部满足才称“值得准备单变量学生确认”，不是方法成功：

1. 原候选/NMS身份验证通过，确认集≥500个主要分析框、≥30个错类，
   且r≥0.25的框≥30；不足时记`INSUFFICIENT_SUPPORT`。
2. 设计集candidate的r系数为正；确认集log-loss相对降低≥1%、
   Brier降低>0、AUROC提高≥0.01。
3. 固定seed20261104、1000次确认原图bootstrap，保持两个模型和所有系数固定；
   baseline−candidate的平均log-loss差的95%百分位区间下界>0。
   此区间仅是该教师/设计模型条件下的图像抽样不确定性。
4. 未标注128图positive中r≥0.25至少30框，且确认集至少两个预测类别各有
   ≥10个错类。防止仅凭无训练域支持或单类别极少量事件推动训练。

任何条件不满足原样报告；不调整r阈值/样本/continue线追试。
若仅通过部分条件，可列出信息价值及不足，但本轮不交付未经论证的学生训练命令。
所有拟合只用开放标签，隐藏GT/val不用于拟合或模型选择。
已有P1成果完全保留；本协议与原Gate3/4独立。
