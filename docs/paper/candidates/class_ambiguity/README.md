# P1 + 类别歧义感知分类监督：候选合同

日期：2026-11-02。状态：`PLANNED / NOT IMPLEMENTED / NOT TRAINED`。
本目录只整理候选，不是已完成方法、可运行实验包或已验证创新。

用户要求在现有P1成果上增加改进。对照为**原P1**，候选为**原P1加一项分类监督变化**，
而不是替换原方法、从B2重新开始或叠加以往失败的模块。
原P1仍是第一篇已完成的主结果；候选失败也不改变它的数字、名称和证据身份。

## 1. 动机和未知项

正式100轮学生在全尺寸precision≥90%、IoU0.50时，P1相对B2的small召回
下降0.2446/0.1618pp。原缓存诊断中多数丢失目标仍存在，只是低于操作点阈值。
P1的wrong-class约占该操作点FP的67.5%，但B2也相近；这不是P1独有根因的证据。

现有伪标签保存top1类别和分数，不能区分“car=.60、van=.59”和
“car=.60、van=.05”这类同top1分数、不同竞争类别结构的候选。
额外信息是否能区分类别错误、是否改善学生排序，均未验证。
YOLO分类输出是各类别sigmoid分数，不是和为1的softmax概率；不得直接把它们当归一化后验。

## 2. 叠加边界

| 项目 | 原P1 | 候选允许的变化 |
|---|---|---|
| 标注区域、教师、初始化、增强、训练预算 | 已冻结协议 | 不变 |
| 尺度筛选、接受框、类别、tile清单 | 原35067正伪框及原元信息 | 不重选框/改类别/扩候选 |
| 原最高分c分类软权重 | 保留 | 额外查看完整类别分数是否有独立价值 |
| uncertain-ignore | 保留 | 不扩大或缩小屏蔽区域 |
| 网络、回归损失、TAL算法 | 原P1 | 不加入新头/NWD/回归加权/分配保护 |
| 伪正anchor分类项 | 原c缩放整个BCE向量 | 唯一研究变量；具体规则在独立诊断后冻结 |
| 人工标签监督 | 原监督 | 不软化真实标签 |

“保持TAL算法”不等于两个训练过程逐步分配完全相同；参数学习会改变预测和分配。
必须审计分类损失总量/梯度份额，排除只减少监督强度造成的假归因。
不能简单把原c改名为“歧义可靠度”，也不能以软标签本身作为首次创新。

## 3. 先做有界诊断，再决定是否训练

下一步可实现一个独立教师分数提取器；本轮尚未实现或执行。

1. 在读取诊断结果前固定训练原图样本清单、上限及随机seed；
   按原图隔离设计样本和确认样本，不能让同图裁片跨组。
2. 用固定B1教师和原预处理/NMS流程保存完整类别sigmoid分数、top1/top2、
   预测框、原候选身份和模型/源码哈希。必须先证明提取后原框、top1分数及NMS选择可重放；
   不能用新推理中“最近的框”静默代替旧伪框。
3. 先用开放标签区域分析信号。在固定top1置信区间内比较歧义与类别正确性的关系，
   同时按尺度、类别、样本支持数报告，避免把原c作用重复归因给margin。
4. 隐藏GT只做锁定规则后的描述性审计，不拟合阈值、挑类别、挑loss系数或选择机制；
   最终val也不用于这些拟合。若看过隐藏GT后改规则，必须记录该探索污染并另取确认依据。
5. 输出有效/无效/样本不足三种结论。没有比原c更明确的信息就停止，
   不为“必须有新模块”而进入训练。

诊断并不证明类别歧义是训练因果；teacher的训练区域分数与最终student错误还隔着训练过程。
尚未锁定数值继续线，必须在读取新诊断结果、尤其训练结果前另存协议，不能事后选线。

## 4. 若诊断支持，怎样做唯一训练对照

准备 `p1_class_ambiguity` 独立模块、显式opt-in配置和runner，默认关闭；
不得修改原P1默认行为。训练前先验证关闭开关时与原P1损失一致，
启用时只作用于伪正anchor分类项，人工标签/ignore/box/DFL按原规则执行。

第一次性能确认须为完整30 epoch，与原P1在同split、教师、初始化seed、
伪框/增强/总预算下配对；若复用历史30轮P1，必须先通过输入/版本/参数一致性审计，
否则重新准备独立配对对照，不能拿100轮P1充当30轮参考。

同时报告总体AP、AP_small、固定点small recall、P70/P90下small recall、逐类结果、
分类监督强度及耗时。新增目标是改善高精度排序并保留原覆盖收益，
不能只选择有利指标判成功。扩大到100轮须先满足冻结的继续条件，由用户启动。
失败产物单独保留，不能覆盖原P1，不能与原P1 seed合并计算均值。
