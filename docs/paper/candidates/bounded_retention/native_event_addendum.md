# 原生TAL事件候选修订：保留版本1的停止结果

2026-11-05，执行新验证前保存。integration_03在第二batch按版本1合同停止，不能改判PASS。
首个阻塞的合法输出框为[585.4102783,52.0062065,591.2327881,59.2844429]，只有top属于U。
可见框内没有锚点；但原P1 tiny-box TAL池包含stride8的(588,52)。
三个E距离均非负且在支撑内，负的只是U-top名义距离−0.000775814。

两份独立复核认定：U是待枚举变量，其名义可见边负距不能推出所有合法未知原子为空。
因此另立版本2；不改旧consumer合同、原实现、03结果或快照，也不把这项改变藏成数字容差修补。

版本2统一定义：

`A_legal = {a in A_native_P1_TAL : d_E(a) in [0,K-1-.01], S_a nonempty}`。

`S_a`固定全部原P1 E坐标，只枚举U的原DFL bins0..15，并逐个经过原联合物理外集、
原保留面积条件、累计增强裁剪、图像画布与正面积约束认证。U名义负距不被clamp成0；
bin0与其他原子一样必须认证。E负距或超支撑仍拒绝，绝不饱和E来伪造合法目标。

- 候选池不得超过原P1 TAL池；不是要求最终正分配与原P1相同。
- 两臂共享S、合法候选mask、TAL质量、CIoU选点和权重；仅未知概率sum/max不同。
- 全known继续原P1逐位等价；原已知坐标、来源区间、对象/实例身份完整保留。
- 不是只救上述个例：同规则用于全部U-only名义负距，正反例验证后重做首epoch增强流检查。
- 若E非法或S为空导致整个对象无合法锚点，仍按先行fail-closed原则停止，不删除对象或加溢出头。
- 真实反例的累计clip域也必须保留；理想合成中可行的某个原子不自动在真实记录中可行。

本修订依据来源/数学一致性，不使用性能、验证集或隐藏GT。尚未放行学生或冻结最终强控制。
