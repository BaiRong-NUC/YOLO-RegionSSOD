# V4数值实现补充（先于生产数值验证）

2026-11-05。连续U使用float64的DFL连续扩展，cap为binary64常量14.99；原E和全known
路径的目标dtype及原生DFL运算不变。物理坐标与编码目标分别保存，不用编码clamp移动框。

实现可直接积分`exp(a(u))`，其中`a(u)=sum q_jk(u) z_jk`为插值logit。
因为`ell=sum_j logsumexp(z_j)-a(u)`，两项log积分中的softmax常数严格相消。
这不改变密度目标；控制的DFL最优值差也恰好等于插值logit最大值差，可用有理数
嵌入有限输入logits做分段仿射上下界。最终控制仍计算完整point-DFL，不遗漏softmax项。
如为数值稳定减去各边detached常数，C和D必须使用相同常数，并恢复需要的绝对积分。

正常化域D可按轴分解。某轴两侧均为U时，left<right三角域以anchor为界分成中心矩形
和两个三角区；在左三角内right距离为负，右DFL编码恒bin0，右三角对称。
因此三角积分只需分段指数的零阶/一阶矩，不必把三角边界近似成矩形栅格。
canvas外anchor的退化分段须同样检查；真实native anchor在canvas内。

几何/全局点界的有理认证与指数积分的浮点误差是不同证据。必须报告实际算术预算及
核对范围，不能用高精度对拍偷换形式化向外界，也不能把正常训练精度要求任意升级为
对整个软件栈的形式化证明，再据此宣布机制不可能。超出已验证数值域则显式失败，
不静默clamp质量或丢掉实例；这一数值边界两臂相同。
