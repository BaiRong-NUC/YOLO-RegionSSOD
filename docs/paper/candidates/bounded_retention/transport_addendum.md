# 累计裁剪与数值外集：真实检查前的修正

2026-11-05。独立增强复核给出两类纯合成反例，当前工程门仍未放行。

1. 原tile左边0经Mosaic平移−4并裁到0，再经RP `x'=0.5x+6`：
   原边的合成affine位置为4，但实际输出左边为6。仅以最后画布判断U会漏掉中间确定裁剪。
2. 相同最终affine和tile可见窗口不唯一决定增强裁剪域。例如源affine都是`32x+20`、
   tile窗口都是[20,52]，先平移28再缩放.5/平移6的裁剪域为[6,64]；
   先平移38再缩放.5/平移1的域为[1,64]。未知边原子4只在后一域可出现。

因此独立运输原tile窗口之外，还必须累计增强裁剪域及其数值界。
原始U永远保存；只有原边的整个允许区间已确定落到累计裁剪域之外，才将该输出边恢复为E。
新裁剪不主动把原E变为U。原始来源框与保留界继续约束裁剪前的物理见证。
输出原子恰在裁剪边时，其逆像可以是半无限区间，不能用单点逆变换替代。

固定E的几何直接使用原P1名义坐标；不能通过`anchor-distance*stride`往返重建。
例如float32的1e−6在anchor64/stride8下往返变为0。DFL仍使用原距离计算及原实现。

来源与运输的证书均须准确称为**保守外集**：来源包含十进制序列化、IEEE运算和选择比较的误差，
运输对每一步binary64乘／加／逆除法作向外区间包络。它们证明合法来源与变换被包含，
不证明外集每个见证都能重放出历史五列文本，也不证明每个向外包络端点都可达。
联合来源xywh约束仍由同一物理见证满足；候选与MAP必须使用同一外集。
不能把外集近似的接受判定写成精确历史导出逆像认证，也不能把独立区间称为学到联合相关性。

完整来源与增强记录尚需通过实际dataloader、零步骤模型检查；上述修正本身不是训练许可。
