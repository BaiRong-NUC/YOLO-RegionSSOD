# 连续曲面集合数值容量检查

2026-11-05，正式容量执行前冻结。此前512-cell纯合成探查仅揭示效率问题，
不能充当20,000预算检查，也不能据此否定连续机制。

固定理想公开观测xywh=(1/2,9/10,1,1/5)，来源阈值仍为0.35−1e−12；
仿射scale=(64,64)、offset=(64,64)，精确clip=[0,256]^2；名义框
[64,115.2,128,128]。活跃U为left/right/bottom，E-top不改。
anchor=(96,120)、stride=8，三边16维logits全部0。

检查完整C，不以一个内部矩形代替整个曲面集合。先查全局point-DFL gap≤1e−5，
再以原默认max_cells=20000运行积分，要求原质量/梯度相对误差≤1e−4。
源代码和本合同先复制到新的ignored receipt目录，进程仅导入该份快照。
保存PID、命令、版本、源码hash、耗时、所有资格与失败诊断，不覆盖旧结果。

独立体积参照：令A=(1/5)64²/tau、h=B−576/5、h0=64/5，
h1=A/128、h2=A/64。横向截面在[h0,h1]为64A/h−6144，
在[h1,h2]为(A/h−64)²/2。用其对数/有理原函数计算体积，
应落在返回的完整C质量包围内；该数值参照不是算法自身的形式化认证。

容量失败只判定当前矩形积分实现未通过此工程门，不宣称集合空、连续定义无效或
所有数值方法不可行。目标不变的后续算法仍须另写合同、独立验证，不能直接放行训练。
本检查不加载检测器、数据、checkpoint或验证标签，optimizer与学生训练均为0。
