# V4连续见证的数值表示补充

2026-11-05，独立反方发现有理相容点转为最近float64后可越过C边界。
不得把转换后的坐标再声称为另一个已认证物理见证，也不新增float可表示性门删除对象。

相容性及全局点控制仍绑定原Fraction坐标和联合source见证。控制DFL直接从Fraction
距离求两bin插值权重，再用float64计算log-softmax加权；禁止由近似几何反算该目标。
单边权重转换的精确误差乘相邻logit差，累加后加到全局point gap；连同保守float64
计算预算必须≤1e−5。全known及E仍保持原P1逐位路径。

TAL/CIoU以float64计算同一个Fraction几何见证的数值近似，两臂一致；保留逐坐标
精确舍入误差。它不构造新标签，不回写E，不冒称所有实数几何能被二进制精确表示。

连续开集未必存在全局字典序最小点。确定性tie明确为：在算法找到并已认证的可行
见证中，先取最高raw score，再按最终xyxy字典序。所有点仍须满足全局目标gap；
不宣称近并列点梯度一致或原合同字面“全局字典序最小点”已实现。
