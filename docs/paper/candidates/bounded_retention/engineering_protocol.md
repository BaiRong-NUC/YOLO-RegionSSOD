## 2. 分级门与执行顺序

1. **S 来源门**：核对旧合法审查results/receipt、自身SHA及6471人工标签绑定、公开参数调用链。
   从`.10g`序列化推导保守区间（十进制有效位舍入与二进制计算误差分开）；严禁事后epsilon调样本。
   不把触边叫真实cut。必须能说明每条边有哪些相容解释、精确值来自哪里。
   原合法坐标全部保留；若只有主动丢弃精确值才有信号，停止。
   若允许来源仅能证明较弱集合，必须先判断是否仍符合当前科学合同，不能静默替换。
2. **T 运输门**：独立候选对象ID与每次载入/增强实例ID，裁剪、缩放、平移、翻转、过滤、拼接、Format/colllate均对齐。
   运输原面积界（缩放乘面积因子），不能以新裁后可见面积重新推导旧保留界。
   不支持旋转/透视等变换必须显式拒绝或有预先声明且两臂一致的作用域，不能伪造标签。
3. **L 消费门**：TAL候选位置不扩张到未知区域；质量、IoU及DFL使用同一观测集合。
   精确边仍为原DFL，未知边在固定精确连续坐标下计算集合质量；全已知走原实现，权重与归一化严格一致。
   负距、有限支撑、空集合、非有限数值要有显式状态，不能用clamp假装集合非空。
4. **C 控制门**：合成比较均值点、唯一众数、同集合MAP和总概率质量，检查损失与梯度，
   包括均值/众数相同、全质量可行、面积跨边不相容、非整数精确边、支持外空集。
   优先用同集合最大原子概率（MAP）作为强匹配分布集中控制；最终选择必须结合零训练证据说明并冻结，
   不用验证集性能挑控制。与候选共享TAL/IoU及所有侧信息；不能仅用无界CABB或弱点目标。
5. **I 集成门**：完整检测loss前后向、全部精确分支与原P1数值/梯度等价、真实Trainer初始化及train/val dataloader，
   验证正常无训练metadata输入；检查继承MRO，避免V1的错误super。模型检查零optimizer步骤。
   源码变更后执行`python -m pytest`。单元合成不能代替真实增强或Trainer检查。

任一必要门无法证明则停止依赖工作，保存可重放证据及具体缺口；不为达成三臂而削弱门。
通过全部门之后再冻结三臂配置/完整学生合同并启动，不再询问开训许可。
