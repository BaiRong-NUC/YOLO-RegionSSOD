## 问题与不可变项

原失败来自共享全局连续点求解，原请求的logits/完整观测未持久化。
先检查现有证据可恢复性；如不足，所有新反例/检查只能称同类压力检查，不能称原失败重现。
源集合C、名义已知E、连续插值与归一化D、候选集合质量目标、控制inf_C point-DFL、
权重和全known原P1等价分支均保持。不得新增信息、主动降级标签或排除难对象。
两臂必须使用同一个求解器和同一个确定性同分选择规则生成TAL/CIoU几何。
单凭控制目标差小不保证框/分配/梯度相同，必须分别报告；旧搜索的遍历相关同分点
变化不能伪装为逐位等价。若这一点改变实际监督，结论限定为同目标算法修订。

1. 只读来源/代码审查，检查分支定界的合法上界、可行见证、开边界和运输。
   提出可证明的上界收紧、无损早退出/缓存或算法替换；所有剪枝须保留原C。
2. 新文件实现候选求解器，不改冻结生产入口。保持原算法作为对拍参考。
   优先考察精确可行最大值早退出、源域条件投影收紧和重复查询消除；不预先宣布可行。
3. 先合成：1U/2U/3U、面积耦合、插值内部位置、正负/区间缩放、clip、已知边画布外、
   饱和、开边界、同分以及尖锐logits。固定随机种子20261106，最多24个新多U压力请求；
   每个参考/新请求最多120秒墙钟预算，超时另记，不能视为求解通过或增大计算限额。
   超时仅结束本轮独立基准子进程，不触碰其他用户进程。
4. 只有算法正确性检查通过才做真实零训练集成。用原合法训练loader和冻结输入，
   固定seed0、batch8；先检查mosaic开启的首16批及关闭的首16批，不按耗时/结果换批次。
   覆盖不足可另报告既有fixed maximum-U压力批次closed1316，须披露额外扫描成本。
   原初始化权重和既有候选第9轮last.pt只用于冻结前向诊断，不读取隐藏GT、
   不调用train/optimizer.step/验证集推理；训练模式前向若更新BN，前后还原并认证。
   若单次loss超过120秒，结束该独立诊断并保留输入，不丢此项继续筛出有利均值。
5. 全库`python -m pytest`；原P1全known值/梯度、同界控制强度、共享几何/分配、

## 成本与判定

计时同机器、串行、不并行实验；GPU操作同步后计时，报告设备、线程、缓存冷热、
前向/分配求解/loss/反向/数据准备的可获得分项。无明确剖析的差值不做因果归因。
微基准报告全部成功/失败/超时分母、median/p90/max及配对总时间；失败项不从总体删除。
真实检查报告所有预定批次和估计范围；预测训练成本必须计入数据/前向/反向等未提速部分。
“明显提速”的本轮预定口径：同一固定完整loss基准总耗时至少2倍加速，且无新增失败；
仅核函数2倍不能据此认定训练加速。未过线可报告局部收益，不修改门槛。
三臂成本仍需按每臂各30×1414批估计，含原P1/控制，不只估候选。

结果分别判定：数学/数值资格、同目标/同控制公平性、原故障复现能力、真实工程资格、
速度与预算。只有全部可获得证据支持才称修复有效；未知保持未知。
