## 首选方向与可辩护边界

本轮选择**人工同对象的正分类目标几何重排**。既有强负监督减少FP却损伤覆盖，
因此不再改负类BCE，而检查已分配正锚点的分类目标是否把质量分给定位较差的预测。
它新增的是**同对象正目标顺序必须与当前人工GT IoU一致**的约束，
没有额外数据源、教师模型、网络分支或伪标签。定位质量与排序监督已有TOOD/VFL/RS及2026 FSS等先例；
本方案的特定区别是人工来源限定、固定TAL与回归、每对象原目标值集合守恒。
这是一项可反证适配，**尚未建立论文新颖性或性能贡献**。

设原TAL对增强人工对象g分配的有效正锚点为A_g，原实际BCE dtype真类目标为t_i，
当前预测框与增强人工框的普通IoU为u_i（detach）。将同一组t_i由小到大，
分配给u_i由小到大的锚点。等IoU保留原目标顺序；零质量、单锚点、全平几何不动。
分类只收到重排后的t；原TAL输出仍供分母、box/DFL使用。伪框和负类目标完全不改。
来源来自显式object_is_human/类别/token表，不由置信度推断。

这个约束保留训练目标质量总量，**不保证学生召回**。跨对象质量总量仍继承原TAL，
没有直接解决占主要比例的错类FP，也不能恢复没有正锚点的目标或缺失伪框。
它同时改变分类分数自依赖的次序与普通IoU/CIoU的次序，成功后也不能只归因“打破自强化”。

## 最多三个方向的比较

| 问题 | A：同对象正目标几何重排（首选） | B：可靠区域跨锚点正负排名 | C：教师多视图一致性可靠性 |
|---|---|---|---|
| 具体误差/信号 | 高质量低分正框排序；已分配锚点的目标、预测框、GT IoU | 真正正框排在可靠背景之后；需完整标注空间的负候选 | 教师跨视图类别/框不一致；需一对一实例对应 |
| 训练时可得性 | 当前预测、增强人工GT及显式来源均可得，detach | 人工对象来源可得，但负锚点空间来源不能从对象来源推出；mosaic/丢框须另运输可见区域 | 固定教师额外离线前向可得，但现缓存多为同教师post-NMS，不独立 |
| 比P1新增什么 | 去除目标顺序中的分类分数依赖，固定原值集合与TAL/回归 | 直接跨锚点相对正负约束，超出逐锚点BCE | 新视图证据/可靠性，而非同一分类标量再加权 |
| 旧失败不直接否定 | 未改负类/伪框回归/分配覆盖；旧变量不同 | 旧人工竞争负项仅同锚点非真类，不是跨锚点排名 | 旧翻转/上下文规则不穷尽一致性；但现有反证使重试期望降低 |
| 最可能失败 | 把分类质量搬给回归支持较差的框外锚点；本就有TAL/人标迁移不足；对象内改善不能纠正跨对象错类排序 | 未知区域负例污染；仍靠压低分数损召回；pair数/强度混杂及计算代价 | 共同错误、拥挤错配，稳定性与真实质量不等；筛掉小框损覆盖 |
| 最近机制重叠 | TOOD已质量对齐，RS已正样本质量排序，VFL已IoU软目标；这里不换TAL或新增权重 | RS/AP排名已有，不能声称hard-negative或ranking首创 | Soft/Humble/Consistent Teacher等已有；不声称一致性首创 |
| 零训练反证 | 实际BCE dtype无逆序/搬移极小；人工来源缺失；回归/伪来源不变量失败；框外/CIoU流向反证 | 若无法证明负候选被完整标注，或排名错误不集中可靠区域，则停；现缓存不足 | 旧翻转新增匹配率约31–37%且组合精度低于基线；旧上下文唯一纠错改坏，当前不重启 |
| 完整验证成本 | 新P1/候选/匹配扰动控制各30轮，90学生轮；最近三臂约8小时，新增排序开销另计 | 先实现空间来源运输/缓存审计，再至少三臂90轮；额外pair开销，暂不投入 | 新独立视图缓存及可靠性反证，再同量/覆盖控制三臂90轮；教师成本另计，暂不投入 |

## 支持、反证与控制

先保存独立[混合缓存协议](../../diagnostics/positive_quality_transport/protocol.md)，
再计算统计；来源不足后另存[单batch补充协议](../../diagnostics/positive_quality_transport/source_check_protocol.md)，
最后按[工程合同](engineering_protocol.md)重放实际CUDA AMP完整loss。
所有旧开发数据都已查看，8图便利batch不是独立确认；不读隐藏GT或追加val推理。
混合48批支持信号存在；实际AMP人工small多锚点126个中100个有目标/IoU逆序，
32个存在>.05的IoU差逆序，搬移原small目标质量8.7506%。
加权IoU改善是排序构造性质，不是机制/学生收益。

反证同样保留：实际AMP人工small框外目标质量35.3208→38.6970；
可能增加分类/回归空间不一致。普通IoU与CIoU排序也不同，不能现在改成仅框内/CIoU重试。
完整正负结果见[诊断报告](../../diagnostics/positive_quality_transport/results.md)。

控制匹配同对象有效支持、总目标质量及相对P1的目标搬移L1；方向来自固定散列，
必要时使用原目标反序方向后凸插值，不读几何排序、不消耗训练RNG。
这匹配局部附加logit梯度L1，不能匹配最终绝对梯度/参数梯度；
控制不保持目标值多重集合，改变锚点数量也可能不同，仍有分布/作用范围混杂。
凸插值可能软化目标；反序fallback也可能破坏原TAL顺序。这不是中性“完全无几何”控制：
几何决定标量预算，非几何方向决定搬移。局部同状态匹配不意味着两个独立学生未来30轮
累计扰动相等，必须同时看control−reference，不能只看candidate−control。
候选必须同时胜过P1和控制，不能只因破坏性控制更差就声称新贡献。
任何继续资格只表示值得另行确认，不能直接证明语义机制。
