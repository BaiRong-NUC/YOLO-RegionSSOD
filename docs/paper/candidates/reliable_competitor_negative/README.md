## 假设与最小动作

原P1的覆盖收益保留，但高精度排序受高分错类限制；继续放松伪框竞争类负项会放松
正确负监督，并保留错top1目标。本计划改为利用**已经匹配人工GT的正锚点**，
检验增强其最难竞争类别的区分能否减少错类FP、提高AP，而不损失原P1覆盖。
它不假定当前错类FP全部来自错误伪标签，也不保证人标区域增益会迁移到val。

对原P1 TAL已经分配到人工GT、实际BCE正质量>0的锚点，设真实类y、当前学生
sigmoid概率p（只用于选择，detach），令k=argmax(c≠y) p_c，类别并列按固定ID顺序。
仅将第k类原负BCE乘数由1改为**2**；其他负类、正类目标／权重、伪框全部监督、
ignore、TAL规则／分母、box／DFL保持原P1。没有新网络分支、教师推理或阈值调节。

不得把未标注背景当可靠负样本；不得仅根据pseudo_weights是否等于1来判断人工来源。
必须传输对象来源标记，随mosaic／裁剪等增强保持GT对象／类别身份，fail closed。
零有效正质量／FP16下溢锚点不执行附加动作，不从全零argmax恢复正类；
真实分类目标与来源检查和数值检查分开。该边界不按val调参。

动作只借用现有人工标签，不增加标注面积；其梯度影响仍会通过共享特征扩散，
不能把“正项不直接改”说成整个模型其他输出不变。

## 反证与控制

- 人标GT正锚点本身可能已学得很好；主错误若来自伪标签偏差，加权人标负类可能无收益。
- 拥挤目标的异类重叠可能使“当前锚点的负类”对应邻近真实目标，加权会加强冲突。
- 新增监督可能只改变总强度而没有语义定位收益；没有控制不能确认机制。
- 该设计就是可靠来源上的困难负类加权，已有hard-negative mining、S³OD等近邻，
  不先宣称算法新颖性。

独立三臂：原P1、目标竞争类增强、**同一人工正锚点／相同新增负logit梯度L1控制**。
控制在所有c≠y上统一乘 `1 + p_k / sum(c≠y)p_c`，固定detach；其新增负梯度和
目标动作的p_k一致，正类乘数1。这只匹配局部分类logit梯度L1，
不匹配参数梯度／后续TAL／优化动态；不能宣称完全消除强度混杂。
sigmoid极端下溢时使用稳定精度并显式保持零新增梯度，不靠大比例随机类补偿。
本轮不增加随机类第四臂，避免成本膨胀；未来若需随机控制，必须另行预注册。

附加动作只落到人工正锚点的非y类、未触发样本与原P1梯度相等、语义／控制新增
负logit梯度L1相等、AMP／零质量边界和参数不变。前向／张量重放不是性能证据。
本次只完成计划，没有执行这一步，也没有候选源码／可直接启动的训练命令。

## 新方案的拟定性能线（训练前冻结，不能追认旧V2）

主目标是提高可靠区分，不以降低召回换FP漂亮数字。候选−新原P1全部要求：

| 指标 | 固定通过条件 |
|---|---|
| Ultralytics AP50–95 | ≥+0.10pp |
| COCO-style AP_small | ≥0pp |
| conf.25／IoU.50 small recall | ≥−0.20pp |
| IoU.50/P70、P90 small recall | 分别≥0pp |
| IoU.75/P90 small recall | ≥0pp |
| conf.25／IoU.50全尺寸FP | ≤原P1的97% |
| 同一固定FP类型分解中的wrong-class FP | ≤原P1的95% |

同时要求候选−等强度控制的AP50–95≥+0.10pp、AP_small≥0pp，才建议进一步
确认针对性信息；否则仅能报告增加可靠负监督的强度效应，语义机制未建立。
这些是对**新假设**的投入门槛，不是统计显著性标准；原V2的七项失败不被改写。
至少完整30轮才能判性能，任何性能／机制线失败即停止，不在当前val调2倍系数、
锚点筛选或类别名单；全过也不自动100轮，需另做学生seed和独立区域split确认。
