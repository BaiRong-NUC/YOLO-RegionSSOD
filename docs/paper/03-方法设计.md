# 03　为同一功能找不同实现

本项目关心未标注区域中的小目标如何给学生提供训练信号。直接比较 [YOLO11s 基线图](figures/yolo11s-architecture.svg)和[P1 训练图](figures/p1-training.svg)，可以看到改动落在教师生成标签和学生计算分类损失的两处。

| 功能 | B2 统一阈值自训练 | P1 的实现 |
|---|---|---|
| 选择正伪框 | 各尺寸阈值均为 0.50。 | 按原始裁片中的框面积分组，小框阈值为 0.30，中、大框为 0.50。[选框代码](../../src/regionssod/pseudo/scale.py) · [阈值配置](../../configs/pseudo_p1_10.yaml) |
| 使用正伪框 | 将入选框作为普通检测标签。 | 在匹配到伪框的正位置，用教师置信度缩放分类损失。[损失实现](../../src/regionssod/training/p1.py) |
| 处理不确定区域 | 沿用常规背景分类监督。 | 在不确定框内屏蔽背景位置的分类损失。[方法及公式](methods.md) |

按尺度筛框、教师指导负学习在 S³OD 中已有先例。[与 S³OD 的逐项比较](s3od_comparison.md)说明本项目如何在局部面积标注、固定离线教师的条件下使用这些思想。当前可追溯的主比较是 B2 对 P1；同协议直接移植 S³OD 的实验仍缺。

若小框筛选确实贡献了增益，固定软权重和背景处理后，仅改变阈值也应产生差异。该问题已有[全局阈值与尺度阈值的配对消融](results_tables.md)。更多尝试及其处置见[代码与改进点索引](research_tracks.md)。
