# 4 实验结果与分析

## 4.1 数据与实验设置

本节在 VisDrone 图像检测数据上分析区域局部标注条件下的检测效果。训练集包含 6471 张原图，验证集包含 548 张完整原图和 38759 个目标实例。训练时，每张原图生成一个人工标注 tile 和一个未标注 tile，固定标注面积比例为 10%，实际平均比例为 9.993%。标注 tile 中保留 105058 行目标标签；按相同裁剪与可见性规则统计，未标注 tile 中另有 38245 个可见隐藏 GT。完整训练标注用于构造这一局部标注协议及离线诊断，隐藏 GT 不作为未标注区域的训练标签。

检测器统一采用 YOLO11s，学生从相同 COCO 预训练权重独立初始化，训练输入为 640，batch size 为 8，优化器为 SGD，初始学习率与末期倍率均为 0.01，momentum 为 0.937，weight decay 为 0.0005。区域 seed 与训练 seed 均为 0，学生独立训练 30 epoch，保持相同增强设置，并在最后 10 epoch 关闭 mosaic。教师为在人工标注 tile 上训练 100 epoch 的 B1 模型；B2 与 P1 共用该固定教师。

训练期间在 640 输入上验证并保存 best.pt，随后统一使用 best.pt 在完整验证原图上以 960 输入评估。验证不裁成训练 tile，以避免将局部区域表现替代完整图像检测效果。开发指标来自 Ultralytics 8.4.172。以下结果属于同一 split、单 seed 的开发对照，比较对象是相同学生 epoch，而非相同计算量。所有数值表见[论文结果表格](results_tables.md)，来源和冻结权重见[证据索引](evidence.md)。

## 4.2 对照方法与指标

B1 仅使用人工标注 tile 训练，反映舍弃未标注区域时的部分监督检测表现。B2 在 B1 教师预测上使用统一置信度阈值 0.50，保留有正预测的未标注 tile，并使用标准检测损失重训学生。P1 使用第 3 章提出的尺度分层阈值、教师置信度分类软权重与 uncertain-ignore。三种方法的学生均独立训练 30 epoch，不能将教师或其他 100 epoch 模型的结果作为同轮数学生对照。

整体检测效果以 mAP50 和 mAP50-95 为主，Precision/Recall 使用 Ultralytics 返回值。为观察小目标召回，另行固定 conf=0.25、类别一致、匹配 IoU≥0.50、NMS IoU=0.70、max_det=500，对完整原图 GT 进行分尺寸统计。预测按置信度降序与所有尺寸 GT 联合一对一匹配后，再按 GT 面积划分 small、medium 和 large，边界分别为 $32^2$ 和 $96^2$。这一固定操作点 recall 与 mAP 的置信度积分口径不同，也不等同于 AP_small 或官方 AR500。

伪标签质量分析针对未标注训练 tile 中的可见隐藏 GT，采用类别一致、IoU≥0.50、IoU 降序贪心一对一匹配。其尺度以原始 tile 内裁剪后的框面积定义。伪标签 recall 衡量教师监督覆盖，完整验证集 recall 衡量学生检测表现，两者分别统计和解释。

## 4.3 整体检测结果

表 4-1 给出了相同学生训练轮数下的对照结果。B1 的 mAP50 和 mAP50-95 分别为 38.277% 和 22.911%；引入全局阈值伪标签后，B2 达到 38.920% 和 23.453%，相对 B1 分别提高 0.644 和 0.542 个百分点。结果表明，在当前局部标注条件下，利用未标注 tile 中的教师预测可以为学生提供有效的补充监督。

P1 的 mAP50 和 mAP50-95 进一步达到 39.499% 和 23.788%，相对 B2 分别提高 0.579 和 0.335 个百分点；相对 B1 分别提高 1.222 和 0.877 个百分点。同时，P1 的 Precision/Recall 为 52.832% 和 38.891%，均高于 B1 与 B2。整体指标的正向变化支持将尺度筛选与不确定区域处理作为区域局部标注下值得继续分析的监督策略。

三种学生采用同一网络与相同训练轮数，使本轮对照主要反映训练监督的变化。B2/P1 的训练 tile 数、每轮 batch 数和额外教师成本高于 B1，因此这些结果应表述为相同学生 epoch 下的收益，而不据此推导同等计算预算下的优势。当前比较也尚不能将 P1 的整体增益分配给三个机制中的任意单项。

## 4.4 完整原图的小目标召回

表 4-2 显示，在固定 conf=0.25 的操作点，B1、B2 和 P1 的小目标 recall 分别为 34.379%、33.815% 和 35.693%。P1 相对 B2 提高 1.878 个百分点，相对 B1 提高 1.313 个百分点。验证集的小目标 GT 共 26577 个，P1 匹配 9486 个，B2 匹配 8987 个，即在同一操作点多匹配 499 个小目标；相对 B1 则多匹配 349 个。

值得关注的是，B2 的整体 mAP 高于 B1，但该操作点下的小目标 recall 下降了 0.564 个百分点。二者并不矛盾：mAP 综合多个置信度阈值下的精度与召回关系，而固定操作点 recall 只描述给定阈值下的检测覆盖。这一差异说明，单一整体指标不足以刻画小目标监督的变化。P1 同时取得更高整体 mAP 和更高小目标 recall，表明其收益在本轮对照中并未仅体现为整体指标的数值变化。

P1 的中、大目标 recall 分别为 77.571% 和 89.410%，也高于 B2 的 76.752% 和 88.097%。不过，小目标 recall 的改善仍是固定操作点观察，不能直接替代多 IoU、多置信度条件下的 AP_small 结论。

## 4.5 伪标签覆盖与精度取舍

表 4-3 中，B2 在 6471 个未标注 tile 中接受 4624 个，tile 覆盖率为 71.457%，生成 27667 个正伪标签框。P1 接受 4839 个 tile，覆盖率达到 74.780%，正框增至 35067 个，另在入训 tile 中保留 52117 个不确定框用于 ignore。P1 的 small 正框由 13266 个增加到 20666 个，增加 7400 个；medium 和 large 正框数量分别保持为 12637 和 1764 个，与只降低 small 阈值的设置一致。

表 4-4 进一步显示，覆盖增加伴随着精度取舍。B2 的正伪标签总体 precision/recall 为 81.473%/58.938%，P1 为 73.200%/67.117%。P1 的总体 recall 提高 8.179 个百分点，同时 precision 下降 8.273 个百分点。对 small 组，recall 从 46.989% 提高到 60.362%，而 precision 从 80.522% 降至 66.830%。按所有尺寸汇总，隐藏 GT 漏检数由 15704 个减少至 12576 个。

这些结果表明，降低小目标接受阈值确实扩大了教师监督覆盖，但同时引入更多错误正伪标签。P1 的软权重设计使较低置信度正框对分类项的影响较弱，不确定区域掩码则避免将部分候选区域直接压为背景。结合学生的整体检测和小目标 recall 变化，可以认为该组合在当前实验中取得了正向的监督利用效果。由于尚未进行单因素消融，现有结果不能证明其中任何一个机制单独造成了上述提升，也不能将数量增长直接等同于伪标签质量全面提高。

## 4.6 逐类别表现

表 4-5 中，P1 相对 B2 的逐类别 AP50-95 在 7 个类别上提高、3 个类别上下降。提高较多的类别包括 bicycle、van、pedestrian 和 motor，增量分别为 1.039、0.950、0.834 和 0.788 个百分点。people、car 和 truck 也有正向变化，说明总体收益由多个类别共同构成。

tricycle、awning-tricycle 和 bus 分别下降 0.618、0.385 和 0.740 个百分点。因而，整体 mAP 的改善并不意味着所有类别均受益。当前按尺度设置阈值，没有进一步区分类别的可靠程度，这一结果提示后续可以结合类别样本规模和错误类型，检查新增低置信度正框是否对特定类别产生额外噪声。现有分类别结果只支持指出这种不均衡表现，其具体原因仍需通过错误案例或消融分析验证。

## 4.7 训练开销与较长训练参考

表 4-6 给出各学生的实际训练规模。B1 使用 6471 个 tile，每轮 809 个 batch；B2 使用 11095 个 tile，每轮 1387 个 batch；P1 使用 11310 个 tile，每轮 1414 个 batch。训练日志累计耗时分别为 3523.76、5073.12 和 7286.61 秒。与 B2 相比，P1 的训练 tile 数增加约 1.938%，日志累计耗时增加约 43.632%。该耗时包含本轮运行条件和训练期间验证的影响，不能单独解释为新增损失计算的开销。

B2 与 P1 还共享一个训练 100 epoch 的 B1 教师，其日志累计耗时为 11460.10 秒，伪标签生成另有离线推理成本。教师和学生阶段应分别记录，以保留实验成本的实际含义。

表 4-S1 将 B1 100 epoch 模型作为较长训练参考单独列出，其 mAP50-95 为 24.883%，高于独立 30 epoch B1 的 22.911%。这一比较说明训练轮数和调度对结果具有实际影响。B1 100 epoch 是部分监督教师，不是完整监督上界 B0；其结果既不能作为 P1 30 epoch 的同轮数基线，也不能以第 30 行日志替代独立的 30 epoch 训练。

## 4.8 本轮实验结论与后续分析

在固定 10% 标注面积与单 seed 的 30 epoch 对照中，P1 将 mAP50-95 从 B2 的 23.453% 提高至 23.788%，并将小目标 recall 从 33.815% 提高至 35.693%。结果说明，针对小目标扩大伪标签覆盖，并对不同可靠程度的候选采用分类软权重和不确定区域处理，可以在本轮实验中获得整体检测与小目标召回的同步改善。这些数值构成方法的初步实验依据。

现有实验给出了组合方法的正向结果及其精度—覆盖取舍，但证据范围仍限定在当前 split、seed 和开发评测工具。后续可优先围绕已有结果补充单因素消融、重复 seed 或错误案例，以回答哪一项机制起主要作用，以及哪些类别需要更有针对性的伪标签控制。完整监督参考、官方 AP/AP_small/AR500 和其他标注预算可作为扩展验证，按论文主张的范围安排。
