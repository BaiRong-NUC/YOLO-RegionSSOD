# 2 相关工作

## 2.1 半监督目标检测

目标检测器的性能依赖高质量的边界框标注，而逐目标标注的成本限制了检测方法在更大数据和更多场景中的应用。半监督目标检测（semi-supervised object detection，SSOD）同时使用有标注数据和无标注图像，以补充监督信号。常见流程是在有标注数据上训练教师或形成初始检测器，再为无标注图像生成伪标签，并使用学生模型学习这些伪目标。

STAC 使用较高阈值保留无标注图像中的高置信度伪框，并通过强增强约束学生预测[4]。Unbiased Teacher 在同一训练过程中联合推进教师和学生，使教师以指数移动平均从学生更新，并采用类别平衡分类损失来缓解伪标签的类别偏差[5]。与只使用硬伪框的做法相比，这类在线教师方法可以利用持续更新的检测能力，但也会引入教师与学生预测及伪目标在不同训练阶段之间的一致性问题。

Soft Teacher 将教师分类分数用于无标注框的分类损失权重，并对回归伪框进行可靠性评估[6]。Humble Teacher 采用丰富的区域提议与软伪标签，并将轻量数据集成用于教师预测[7]。这些工作说明，伪标签不应被视为与人工标签完全相同，置信度可以参与学生损失的构造。Dense Teacher 进一步以稠密预测替代经过后处理得到的伪框，减少伪框生成步骤中的阈值和 NMS 损失[8]。Consistent-Teacher 则从 anchor 分配、特征对齐和动态阈值三个方面处理训练过程中伪目标波动的问题[9]。

这些方法大多面向自然图像，并假定无标注图像不提供任何目标监督。本文面对的是高分辨率图像中的区域局部标注：训练图像并非完全无标注，而是只开放一个局部人工标注 tile，其他区域存在目标却没有标签。该设定需要通过区域构造保留局部监督与潜在隐藏目标的差别，而不是简单地把整张图像在“有标注”和“无标注”之间二分。

## 2.2 缺失标注与稀疏标注

训练数据中的漏标会使未标注目标在标准检测损失中被当作背景。Soft Sampling 通过根据区域与正样本的重叠程度调整采样或梯度权重，降低不确定背景区域的错误负监督影响[10]。SparseDet 将区域提议区分为已标注和未标注区域，并对未标注区域采用伪正样本挖掘与自监督处理，以应对较高稀疏度下的噪声伪标签[11]。两类工作共同说明，缺失标注下的核心问题不只是正样本数量不足，还包括背景定义本身不可靠。

本文的 uncertain-ignore 与上述问题直接相关：教师给出高于候选下限但低于正阈值的框，不进入任务对齐的目标分配，同时也避免其中心覆盖的 background anchor 继续被压为强背景。它与 SparseDet 的区域级伪正样本挖掘不同，也与 Soft Sampling 依赖区域与已知目标重叠的重加权不同。本文由教师候选直接定义不确定区域，并将该区域仅用于筛选负分类项。

需要区分两种局部监督：稀疏标注通常减少图像中已标注目标的数量，而图像整体仍可用作训练输入；区域局部标注则限制人工提供的空间范围，范围外目标可能完全不可见。本文不把区域外像素直接作为纯背景，也不把未标注 tile 的隐藏 GT 用于训练。该协议允许在可控标注面积预算下分析局部监督和未标注区域利用。

## 2.3 航拍图像中的小目标检测

航拍图像具有图像尺寸大、目标像素面积小、目标分布不均和密度变化大的特点。ClusDet 先定位可能存在目标的聚集区域，再对归一化尺度的候选区域进行检测，以减少均匀切块带来的计算浪费[14]。QueryDet 先在低分辨率特征上定位小目标候选，再稀疏查询高分辨率特征，在提高小目标检测效果的同时控制高分辨率计算量[15]。这些方法通过网络结构或推理路径处理尺度与分辨率问题；本文暂不修改 YOLO11s 网络和检测头。

在航拍 SSOD 中，伪标签在尺度上的偏差会同时影响正样本覆盖和负样本学习。S³OD 将问题归纳为伪标签不平衡、标签分配不平衡和负学习不平衡，并分别使用尺度感知自适应阈值、尺度重平衡标签分配和教师引导负学习来处理[12]。Density Crop-guided SSOD 通过识别小目标聚集区域，在训练时扩充小目标密集裁片，并在推理时联合全图与裁片预测[13]。两项工作都表明，航拍图像中的尺度问题不能只依靠一个全局置信度阈值解决。

## 2.4 与本文方法的关系

S³OD 是与本文最接近的参考文献。本文的尺度分层正阈值与 S³OD 的尺度感知阈值处理同一类小目标漏检问题；本文利用教师给出不确定区域，避免把候选区域作为背景，也与教师引导的负学习存在明确联系。因此，本文不能将“首次结合尺度阈值和教师负学习”作为贡献。

本文当前关注的具体问题是区域局部标注下的高分辨率航拍检测。在这一设定下，本文将离线 B1 教师、原始 tile 尺度分层、教师置信度分类软权重和不确定区域负项屏蔽组合进 YOLO11s 的单轮自训练流程，并在完整原图上分别报告整体检测指标、学生小目标召回和教师伪标签覆盖。与 S³OD 的 DOTA 实验相比，本文使用 VisDrone 和以标注面积定义的区域预算，尚未在同一实验配置中直接比较两种方法。

论文可以支持的贡献表述应限定为：面向区域局部标注航拍图像，分析并实现一种不修改检测网络的尺度感知自训练流程；该方法将低置信度候选用于抑制错误负监督，并以教师置信度调节伪正标签的分类贡献；实验进一步给出正伪标签覆盖增加与精度下降之间的取舍。单因素消融、跨 seed 稳定性和与 S³OD 的直接比较尚未完成，不宜据此作更强的领先性结论。
