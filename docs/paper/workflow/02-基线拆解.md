# 02　按功能拆解基线

打开 [YOLO11s 基线图](../figures/yolo11s-architecture.svg)，下半图是 B2 的训练流程。B0 使用完整监督作上界参照，B1 使用有标注裁片训练。B2 以固定的 B1 为教师，为未标注裁片提供训练目标。[实验协议](../../experiment_plan_8weeks.md)

| 跟踪一张图 | 要看什么 | 入口 |
|---|---|---|
| 取训练裁片 | 标注面积预算决定人工监督区域，其他区域仍可能有目标。隐藏真值仅用于审计。 | [区域划分](../../../src/regionssod/data/partial.py) |
| 教师预测并生成标签 | B2 对所有尺寸统一采用 0.50 阈值，低于阈值的小框失去成为正监督的机会。 | [B2 伪标签生成](../../../src/regionssod/pseudo/generator.py) |
| 学生学习 | Backbone 提取特征，融合层汇合不同尺度的特征，Detect 在三个尺度预测类别和框。学生同时使用人工和伪标签裁片。 | [网络图解](../figures/README.md) · [训练入口](../../../src/regionssod/training/runner.py) |
| 在完整原图评测 | 验证保留完整标注。总体 mAP 和固定操作点的小目标召回各有独立入口。 | [整图验证](../../../src/regionssod/evaluation/runner.py) · [分尺寸召回](../../../src/regionssod/evaluation/size_recall.py) |
