# 已开放区域拟合的伪标签置信度校准：执行前协议

2026-10-30。本协议在拟合/独立样本统计前提交，不事后调整继续线。
原图上下文纠错固定规则失败，停止该规则。新问题来自已完成软权重消融：
原置信度加权的整体mAP较高、小目标recall较低；原分数是否等于正确概率尚未证实。
本项不预设校准能提高学生效果，先检验其从开放标注区域向随机未标注tile的迁移。

## 1. 论文依据与差异

已由MCP下载并归档的 *Calibrated Teacher for Sparsely Annotated Object Detection*，
`2303.07582v1`，本轮阅读PDF pp.3–5（Confidence Calibration、Online Calibration、
Algorithm 1）：原方法用logistic校准及稀疏标注匹配队列在线更新，校准后选伪标签，
还包含Focal IoU Weight。本项目不声称首次引入教师校准，不复现其数值；
本项仅固定离线教师、固定已接受正框，检验分组可靠性作为分类权重的候选。
不加入其在线EMA、队列、FIoU，不改伪标签阈值或网络模块。

本区域协议的开放tile内部已有可见GT；可拟合校准器，但存在目标中心裁片分布偏差、
教师已见过这些标注及裁边可见性丢弃等局限。不得假定这种校准自动适用于未标注区域，
也不能用隐藏GT拟合/调参或将结果写为学生AP。与已有尺度阈值工作S³OD仍有重叠，
分组校准通过也不等于独立算法创新已经建立。

## 2. 固定数据、模型与唯一规则

配置`configs/confidence_calibration_diagnostic.yaml`，三组按源图索引不重叠：

1. 排除历史640尺度/NMS和原图上下文样本，seed20261103取512张开放标注tile。
   固定同一B1教师做960/conf0.05/NMS0.70/max_det500/batch2推理，只新增这512张。
   用现有P1阈值保留正框，按同类IoU≥0.50降序一对一匹配开放tile GT，
   以是否匹配作为拟合目标。只用`labeled/labels`，不读取源图完整/隐藏GT作拟合。
2. 固定分数段[.3,.4,.5,.6,.7,.8,.9,1.000001]。先拟合全局分段校准，
   各段加入强度20、均值为段中心的先验，用加权相邻违例合并保持单调。
   再拟合类别×原生tile尺寸组，各段以全局概率为强度50先验并保持组内单调；
   组总数小于50时回退全局。无隐藏GT输入，也无阈值搜索。
3. 不重叠seed20261104取256源图作为探索，复用已有未标注tile的P1正伪框。
   已接受tile才分析，未接受tile单列；拟合后的全局/分组映射完全冻结。
   正框数、类别、几何、原置信度、ignore均不变，不导出训练数据。
4. 隐藏GT仅离线产生正框匹配正确性。比较原分数、全局校准和分组校准的
   Brier均方误差、分尺寸统计、平均权重及错误框占权重总量比例。
   全局校准是必要简化对照，避免将简单分数整体抬升归因为类别/尺度信息。

## 3. 固定继续线和停止条件

拟合正框至少2000、探索正框至少1000、small至少400；
分组映射覆盖至少80%。分组Brier较原分数至少降低0.01，
较全局至少降低0.002，small较原分数至少降低0.005；
错误框占权重总量比例比原分数最多增加0.02。每项必须同时满足。
这些是探索继续线，不是显著性或学生AP门槛。

探索通过后才能用seed20261105取另256张源图确认，继续排除拟合/历史/探索；
只读取既有伪框、不新增推理、不重拟合校准器，全部继续线仍须满足。
失败不调先验、分组、分数段或继续线重试，不训练。
即使两组通过，也需单独登记单因素学生30epoch预算、预检、完整val960及recall。
没有学生效果证据前不交长期训练命令，不创建无训练对象的监控。

本项探索和确认均是已被多轮机制研究使用的数据集上的来源不重叠样本，
不是独立数据集、独立教师或新盲测。
