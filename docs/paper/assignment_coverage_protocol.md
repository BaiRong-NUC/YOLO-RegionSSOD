# 覆盖保护的框内点分配：新规则与新样本确认

2026-10-31，首次运行本规则前登记。初版分配诊断已失败，见
`assignment_geometry_results.md`，不修改其99%覆盖保护线或追认初版通过。

## 1. 新规则与设计来源

初版缩小候选池后，探索/确认分别丢失19/13个原有有效分配的小框。
这些框原本均有框内点，说明“池非空”不能保证最终冲突消解后仍有有效监督。
新规则同时计算原TAL及初版框内优先TAL；若一张图中任何原本有有效分配的目标
在初版分配后消失，则该图的全部分配结果退回原TAL，否则使用框内优先结果。

有效分配要求目标分数>0。保护全部尺度的训练正框，不按隐藏GT、类别表现或
val选择图像；不修改原标签、目标坐标、分类权重、ignore、TAL质量分数或回归损失。
该规则有双次分配开销，不能只报告几何改善而忽略训练时长。
它是基于初版失败设计的保守适配，不称全新框内点思想或S³OD SLA复现。

## 2. 数据与预算

旧256增强输入的缓存已参与规则设计，只用于工程/探索，不再当作新确认集。
从原排序11310训练tile中排除旧256基础tile，以default_rng(20261101)
无放回抽取128个新基础tile；seed20261101+样本顺序，增强、模型和精度
沿用初版。mosaic仍来自完整训练集，故不是独立来源确认或显著性检验。
新增预算仅128个训练增强输入的P1 FP32前向，无梯度/优化器步骤，不读取隐藏GT/val。
保留原始预测和逐目标统计，用CPU精确重放原TAL/新规则的分配。

实现固定于`src/regionssod/training/assignment.py`，
诊断入口`scripts/audit_assignment_coverage.py`。
原P1/NWD源码与结果保持，旧来源校验仍可运行；新文件不回写旧结果的来源清单。

## 3. 同一诊断门槛

新128图单独满足初版所有阈值才值得准备30轮性能确认：
有效small框至少100；至少50个small框含原框外有效点；
框外目标分数占small总质量至少1%；新规则使该框外质量至少减半；
原有效small及全部目标分别保留至少99%；small质量保留至少90%。
不会因为整图退回条件导致减少作用空间而降低阈值。

这些只是工程覆盖和机制作用空间条件，不是精度、recall或AP收益。
若未通过，保留结果，不调本规则参数或继续换样本追试。
若通过，另行冻结完整11310tile、seed0、COCO初始化的唯一30轮学生，
与缓存完整P1比较完整val960与固定操作点recall；更长训练仍由用户执行。
