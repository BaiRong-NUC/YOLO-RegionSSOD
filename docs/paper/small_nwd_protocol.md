# 小框混合NWD回归：执行前协议

2026-10-30。当前只推进A。此前定位稳定性、原图类别纠正和开放区域校准均未
支持扩大训练，不修改这些失败规则。本项换为固定框集合上的几何回归度量。

## 1. 依据和单因素

原始NWD论文`2110.13389v2`已由MCP下载并归入Zotero，PDF pp.4–6、
Sec.3.1–3.3、式7–9本轮核对：水平框建模为高斯，
距离为中心坐标差及半宽/半高差的联合欧氏范数，损失为`1-exp(-distance/C)`。
其C按数据平均绝对尺寸设置，不能直接搬用AI-TOD的12.8到本训练tile。
原论文已将NWD用于分配、NMS和回归，并在VisDrone上实验，
本项不是发明NWD，也不是其原多位置替换方案复现。
已有CIoU本身可对不相交框提供信号，不能声称本项目解决了CIoU“完全无梯度”。
与S³OD的高斯/Wasserstein分配也有重叠，本项只改变回归项，不修改TAL分配。

固定一个候选：增强后的640训练像素空间，目标面积小于32²的正anchor，
将框回归项改为`0.5*(1-CIoU)+0.5*(1-NWD)`。
其余目标沿用CIoU；DFL、TAL权重/分母、分类软权重、ignore、伪框与网络不变。
人工标签和伪标签的小框采用同一几何度量，不用隐藏GT挑选“可靠框”。
640输入上的small条件不同于伪标签原生tile尺寸条件，不能混用两者计数。
特征网格坐标先按各anchor的stride转回像素，再计算NWD，保证不同检测层的单位一致。
零距离使用向量范数的有限零次梯度，距离计算采用float32以避免AMP下数值不稳。

## 2. 常数、检查与预算

C只由已有1024源图子集的1024个开放标注tile计算：
每个框按普通等比例resize至640后的`sqrt(w*h)`，选小于32的框取算术平均。
不读取未标注区域GT，不根据val选择C/mix/面积边界，不做损失超参搜索。
先做解析值、stride/缩放单位、AMP、零/非重叠/包含、梯度、空前景、
DFL不变与关闭NWD恢复P1的单元测试，以及真实YOLO11s的GPU前反传。
通过工程检查仅代表可训练，不代表有效或创新已成立。

复用已验收完整P1的1024源图/1765tile/5epoch参考：
`runs/screen/p1_full_area10_subset1024_e5_s0`，COCO初始化、640、batch8、
SGD、seed0、close_mosaic0，完整548原图val960与固定操作点recall均已保存。
预检须核对参考产物、数据/元信息、训练参数及既有源码哈希；
新增模块隔离实现，不修改已冻结的P1/runner源码。
只新增一组5epoch学生，配置`configs/screen_p1_small_nwd_5ep.yaml`；
总新增预算5epoch，不新增教师推理。实际训练启动时创建临时监控，
保存PID/创建时间/命令、日志、CSV和退出码，不重启或拼接中断epoch。

## 3. 固定继续线

筛查NWD相对同子集完整P1：val960 mAP50-95至少+0.30个百分点、
固定操作点small recall同向（差值≥0），才值得单独登记全量30epoch确认。
不足即停止这项固定规则，不改C/mix/面积阈值重试。
短程数值不进入正式论文主结果表，不与已有全量30epoch直接比较。
本入口不会自动派发30epoch或100epoch；确认协议和用户交接另行记录。
更长训练只有在后续学生证据支持、配置/预检/验收完备后交由用户运行。
