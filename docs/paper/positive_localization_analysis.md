# 已有正伪框的跨尺度定位可靠性诊断

2026-10-30预先记录。本轮仅推进A；软权重全量消融已完成，去权重mAP50-95
下降0.1623pp、small recall提高0.9143pp，不扩大训练。这里检验不同的问题：
已有正伪框的跨尺度几何一致性能否提供分类分数之外的定位质量信息。

## 1. 执行前固定协议

- 固定配置：`configs/positive_localization_diagnostic.yaml`。
- 复用已缓存的原960候选与640视图；探索和不重叠确认各256tile，
  仅分析已被P1接受入训的tile和正框。不增加推理、不训练、不更改训练标签。
- 两样本此前用于别的候选诊断，并不是新盲测集；这里只能检验该问题在不重叠
  tile上的方向。隐藏GT严格只用于离线诊断，不选择训练框或拟合训练期评分。
- 同类、640视图conf≥0.05、跨视图IoU≥0.10，按IoU降序稳定贪心一对一匹配。
  几何量在原tile坐标计算；匹配只读教师预测，不接收任何GT。
- 匹配IoU≥0.70为稳定，0.10≤IoU<0.50为不稳定，中间单列；没有匹配单列，
  不等同于错误框。另报告一对多候选/实例竞争，以提示拥挤目标可能交换身份。
- 主质量量为“同类最近GT的IoU≥0.75比例”，同时报告平均IoU、IoU≥0.50比例、
  原质量协议的一对一匹配率、可能类别错误与重复竞争。最近GT可被重复使用，
  因而不是伪标签precision；一对一匹配率另外报告。
- 主问题限定small正框；在预先固定的0.1宽置信度区间内比较稳定/不稳定组。
  跨层差值按每层两组样本数的较小值加权，排除置信度组成变化的直接影响。
  再按类别×置信度分层检查组成偏差，不因稀疏层无统计就退回未经控制的总均值。

## 2. 仅用于决定是否继续的诊断条件

探索和确认都需满足主条件，不能探索失败后改阈值选另一组合：

1. 每个可比置信度层两组各至少10框，至少2层，累计两组各至少50框，
   可比样本至少覆盖该样本全部small正框的25%。
2. 控制置信度后，稳定组的IoU≥0.75比例高至少10个百分点。
3. 类别×置信度控制每层两组各至少5框、至少2层、累计各至少25框，
   覆盖small正框至少10%，差值不得为负。

这些是离线筛查线，不是论文显著性检验，也不代替学生val960。
覆盖不足即记证据不足，不把没有通过解释成稳定性完全无用。
通过也只支持准备下一项单因素有界学生试验，不能直接发100epoch命令。
