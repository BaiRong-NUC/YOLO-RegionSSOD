# 水平翻转跨视图候选筛选：小样本离线诊断

2026-10-30。随机种子 20261030 从 6,471 个未标注 tile 等概率抽取 256 个；其中 196 个原本有 P1 正框，以下统计仅限这些原有入训 tile，另外 60 个未纳入指标。使用原始冻结 B1 教师及原 P1 post-NMS 候选，水平翻转 tile 推理一次，映回原图坐标；imgsz=960、conf=0.05、NMS IoU=0.7、max_det=500。推理计时约 7.3 秒（含加载等开销，不包括前期已有教师成本）。

原候选仅选预测 small、原置信度≥0.25 的 ignore 框；支持规则要求同类别，跨视图框按 IoU 降序一对一匹配。翻转视图置信度与跨视图 IoU 阈值仅作探索，六种条件均使用同一批推理结果。隐藏 GT 仅离线计数，不参与选框。固定原 positive 对 GT 的同类 IoU≥0.50 贪心一对一匹配，新增框只能匹配剩余 GT；所有 GT 尺度联合分配。

基线为 1,611 正框、1,239 个匹配、1,686 GT，其中 small GT 896 个、已匹配 635 个；整体 precision 76.91%、coverage 73.49%，small coverage 70.87%。直接加入 97 个框后，锁定基线口径下整体 precision 为 74.30%、small coverage 为 74.11%；选择翻转 conf≥0.25 / IoU≥0.50 时分别为 75.33% 和 73.33%。新增匹配/新增框是保守增量指标，包含与原正框重复的候选，不能当成独立伪标签的常规 precision；锁定原匹配的组合计数也不同于重新对全部预测进行匹配。

在此样本中更严格的跨视图支持提高了新增匹配比例，但同时减少可恢复 GT；所有方案的组合精度仍低于原基线。样本量小、同一 split/教师且阈值探索性选择，不能推断显著性、学生 mAP、官方 AP_small，也不能从这些结果断言跨视图一致性无效。当前没有足够强的方向下发训练命令，原 Gate 3 不变。

复现：在已有 yolo 环境运行 `python scripts/audit_cross_view_flip.py`（输出目录必须不存在）；复核并重算已保存翻转预测用 `python scripts/audit_cross_view_flip.py --replay`。输入哈希、随机下标和结果位于本地忽略目录 `outputs/cross_view_flip_20261030/analysis.json`，翻转预测位于同目录 `flip_candidates.jsonl`。如重新推理需先使用新的输出路径或保留/移走旧产物。
