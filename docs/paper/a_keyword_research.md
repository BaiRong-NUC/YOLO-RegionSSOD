# A论文关键词调研与单机制优先级

核对日期：2026-10-30。当前仅推进A第一篇区域局部标注小目标检测方法稿。
用户提出的六类关键词用于寻找有依据的假设，不等同于同时添加六类模块。
以下论文方法不代表已在本仓库取得收益；原Gate3未通过的结论不变。

## 1. 本轮先做什么

唯一一组去分类软权重的完整30epoch消融已验收，复用已完成的完整P1参考。
它回答现有教师前景置信度分类权重是否值得保留，而非验证下列新假设。
去软权重mAP50-95−0.1623pp、small recall+0.9143pp，体现取舍且未达扩大训练线，
见表4-S5/实验4.14。保留完整P1主配置；新损失、教师及模型结构均未改动，
不启动第二组训练，下一项先诊断而非直接训练。

优先保留的研究问题是：**在不增加正伪框的情况下，跨视图几何稳定性是否能
识别已有正伪框的定位质量，从而决定它们应承担多少回归监督？**
该固定规则现已完成两组缓存诊断，分层样本不足，未通过继续线，
见[定位诊断](positive_localization_analysis.md)，不进入训练。
它不是已经成立的新方法或创新性结论。

## 3. 六类关键词如何落到当前项目

| 用户关键词 | 可检验的问题 | 当前安排与成本 |
|---|---|---|
| 漏检测重新生成训练 | 模型未标注目标能否被可靠挖掘，并使独立学生受益？ | R1已有互补视图挖掘；本项目翻转/尺度支持和NMS诊断未支持直接扩训，先停止重复阈值扫描 |
| LoRA大模型微调迁移视觉 | 在固定标注协议下，适配基础模型能否提供独立于原教师的有效证据？ | R8/R9说明可研究参数适配；需额外模型、适配数据和计算预算，本阶段不下载权重或微调 |
| 模型剪枝 | 删掉通道/模块后能否保持召回并减少实际推理成本？ | R11/R12是远期C的依据；权重置零不等同于结构变小或板端加速，不进入A当前训练 |
| 先蒸馏再裁剪 | 强教师向当前模型传递知识，再结构裁剪与恢复，能否在相同精度下减成本？ | 尊重用户提出顺序，作为C的待验证路线；蒸馏/剪枝/恢复需独立对照，不预言该顺序必胜 |
| 效果好的损失函数 | 当前误差来自分类、伪框定位还是错误背景监督？ | 先验收分类软权重，再考虑定位可靠性；NWD为独立备选，不同时替换BCE/IoU/DFL |
| DINOv3、CLIP | 稠密视觉特征或图文语义能否在小目标上提供可分辨的可靠性信号？ | 先查目标像素、patch覆盖、裁剪映射和特征分离；没有证据前不接入主训练，不把整图语义当作框正确性 |

即使以后采用“强模型→当前学生→结构剪枝”，强模型必须遵守相同开放标注范围，
完整标注教师只能作为显式上界参考；模型、预训练和生成成本另记，不能与本项目
固定B1教师的消融直接解释成同预算方法增益。

## 4. 优先假设：分类可靠性与定位可靠性分开

### 4.1 为什么值得先诊断

当前`src/regionssod/training/p1.py`的`classification_factors`只调节匹配正anchor
的分类BCE及不确定负anchor；`bbox_loss`计算box/DFL，不额外乘教师置信度。
所以“分类置信度高”仍可能伴随框位置偏差。R2/R3及Soft Teacher已有定位
可靠性处理，不能把这一问题或跨视图稳定性本身称为首次提出。

前面的跨尺度实验问的是“能否把额外候选升为新正标签”；该假设问的是“现有
正标签应承担多少定位监督”。前者确认失败不证明后者有效，也没有直接检验后者。

### 4.2 零训练诊断设计及本轮结果

1. 只读取已接受正伪框和已有翻转/640输入尺度预测，映射回原tile坐标。
   保留原始标签类别、坐标、数量和入训tile；先审计缓存是否完整及视图映射。
2. 预先固定同类一对一匹配、IoU/中心偏差/宽高变化等代理量。
   没有视图匹配需单列，不能等同于错误框；拥挤目标的实例互换也需单列。
3. 用隐藏GT做只读诊断，报告定位IoU分布、错误类别、重复框、分尺寸及
   无匹配比例；比较相同置信度/尺寸层内的稳定与不稳定组，排除只重复分类分数排序。
4. 先记录探索样本规则，再在不重叠确认样本复核。诊断GT不得用于训练期打分、
   阈值选择器或导出伪标签；候选规则过线也不当作学生收益。
5. 只有具有独立定位区分度且覆盖足够时，另行登记单因素预算和训练指标，
   再考虑新增可关闭的回归可靠性权重；监督GT权重为1，分类、ignore和标签集固定。
   必须核对TAL分母、box/DFL归一化和增强元信息，防止权重相互抵消或错位。

本轮按先提交的固定协议完成上述缓存诊断：两组small不稳定正框各仅6个，
不足以形成控制置信度/类别的可比层，不改阈值重试。未实现新回归损失或发出新
训练命令。已完成消融的输入、训练源码与产物保持冻结；
详细统计及1442输入哈希/2710正框只读重放见`positive_localization_analysis.md`。

### 4.3 损失候选的取舍

若稳定性代理无独立信息，停止该假设。NWD可作为后续定位度量的单独问题：
原论文Sec.3.1–3.2将水平框表示为高斯分布，并用归一化Wasserstein距离衡量相似性。
归一化常数与坐标单位必须明确，不能直接搬用AI-TOD设置到不同分辨率的tile。
其原文也涉及分配/NMS/loss，若本项目测试，只选择一个位置变化，保留原始对照。

R4则提示错误背景监督可能需要可靠负项处理。直接套Focal Loss并不消除缺标
错误，反而可能放大困难伪负样本的影响；此路线也必须单独验证，不能与定位
加权/NWD一轮合并。没有脱离当前数据和误差类型的“最好损失函数”。

## 5. 创新与扩大训练条件

目前可陈述的是区域面积预算协议和可追溯机制分析；仅把已有方法组合到YOLO
不能保证独立算法新颖性。若上述假设得到支持，需进一步核对与S³OD、Soft Teacher、
RUPL、UTv2的权重对象、代理量、分配规则和监督可见范围的实质差异。

顺序固定为：当前30epoch消融验收→选择一项可推翻的离线问题→独立样本确认
→单因素有界学生对照→值得扩大时准备冻结代码、预检和训练/验收命令交用户运行。
中性和负面结果原样入记录；不为了创新叙述同时堆叠基础模型、损失和压缩模块。
