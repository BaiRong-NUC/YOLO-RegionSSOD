## 1. 主线与证据层级

研究问题保持为：在 VisDrone 每图约 10% 面积开放标注的合成区域局部监督条件下，
固定教师、YOLO11s 学生的尺度感知离线自训练，如何改变完整原图的小目标覆盖，
以及这种收益在不同精度要求下有哪些限制？

当前最扎实的结果是**两个学生 seed 重复出现的小目标覆盖收益，以及收益的精度区间边界**。
不是“小目标 AP 全面提高”，也不要求把新的类别歧义候选写成已完成贡献。

## 4. 能辩护的解释与需要收缩的主张

| 拟写主张 | 证据判断 | 保留成果的准确写法 |
|---|---|---|
| P1提高小目标覆盖 | 在当前两学生seed上支持 | 固定点两seed提高；中等精度约束下仍保留部分收益 |
| P1显著提高小目标AP | 不支持 | AP_small方向不同，完整报告 |
| 三个模块都独立提高AP | 不支持 | 尺度阈值有配对证据；其他消融呈现取舍，不能替它们编造增益 |
| 高精度退化由框回归变差导致 | 当前缓存削弱 | 大部分丢失目标仍在完整缓存，只是低于全局操作点 |
| 类别歧义就是已证明的根因 | 未验证 | wrong-class在B2/P1都较多，仅提供进一步检查的动机 |
| 尺度条件后处理提高实际部署性能 | 证据不足 | 缓存继承匹配的跨拟合代理分析；筛选后重新匹配和外部确认尚缺 |
| 相同epoch意味着相同训练成本 | 不成立 | 报告tile数量、训练耗时和教师成本 |
| 首次结合尺度阈值与教师负学习 | 已有近邻工作 | 明确引用S³OD，贡献定位为具体区域协议/实现/可复核分析 |

   接下来处理摘要、图表排版及引用/缩写统一。写初稿无需再训练。
2. **下一步候选只在原P1上加一项**：[类别歧义候选合同](candidates/class_ambiguity/README.md)。
   教师诊断后已完成两臂各30轮：IoU.50/P90收益伴随AP/AP_small/P70退化，
   未通过固定继续条件；[完整结果](candidates/class_ambiguity/results30.md)进入补充/讨论，原P1继续作主线。
3. **按目标主张决定论文补证据**：若主张跨预算/泛化，需要额外预算、新区域split或外部集；
   若主张优于近邻方法，需要同协议S³OD等对照；B0仍缺。它们与候选是否成功是不同问题。
4. **当前变体不扩大训练**：完整30轮已完成但未通过预定全部条件；未来新候选须另行冻结确认。
   同时评AP、AP_small、P70/P90召回、类别和成本，不能以修复高精度为由丢掉原覆盖优势。
5. **候选失败时**：正文仍使用原P1及已保存结果，新候选进入补充失败分析或仅研究日志；
   不重命名、不覆盖、不把候选负结果算进原P1均值。

现有成果足以启动有结果支撑的完整初稿；能否满足目标期刊的创新和实验要求仍未判定。
