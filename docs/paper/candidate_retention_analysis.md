# NMS 与 max-det 候选覆盖检查

2026-10-30，本轮为零训练、有限推理的探索性诊断，不进入论文学生结果主表。
从 6,471 个未标注 tile 中排除上一轮翻转验证的 256 个下标后，以 seed=20261030
随机抽取 128 个；其中原 P1 入训 89 个、排除 39 个，两类分别报告。原入训样本含
731 个隐藏 GT，其中 small 479 个；排除样本含 19 个 GT，其中 small 12 个。
隐藏 GT 只用于离线匹配，不用于筛选或生成训练标签。

## 设置与继续条件

固定 B1 教师、Ultralytics 8.4.172、imgsz960、conf 下限 0.05、batch8，比较：

| 方案 | NMS IoU | max-det |
|---|---:|---:|
| 原配置重跑 | 0.70 | 500 |
| 放宽 NMS | 0.90 | 500 |
| 提高检测数上限 | 0.70 | 1000 |

三组均使用持久化图像清单、流式 batch 推理。原配置在全部 128 个 tile 与冻结 P1
候选的数量、类别、状态一致，坐标及置信度在 1e-4 容差内重现。

推理前固定探索性继续条件：新增框≥20，新增独立匹配/新增框≥50%，新增 small
匹配≥10、small 覆盖增加≥1 pp，且锁定基线口径的组合 precision 下降≤1 pp。
该门槛只决定是否值得做学生筛选，不是统计显著性或原 Gate 3 门槛。

## 结果

下表仅统计原入训 89 个 tile。所有框按类别一致、IoU≥0.50、IoU 降序一对一
匹配，先对全部 GT 联合分配，再按 GT 原始 tile 面积归组。

| 指标 | 原配置 | NMS 0.90 | max-det 1000 |
|---|---:|---:|---:|
| conf≥0.05 候选框 | 1647 | 3438 | 1647 |
| 全候选 GT 匹配 | 617 | 628 | 617 |
| 全候选 small GT 匹配 | 391 | 400 | 391 |
| 达到原 P1 尺度正阈值的框 | 650 | 860 | 650 |
| 正框 GT 匹配（各方案独立重匹配） | 500 | 508 | 500 |
| 正框 precision | 76.92% | 59.07% | 76.92% |
| 触及对应 max-det 的 tile | 0 | 1 | 0 |
| 单 tile 最大候选数 | 213 | 500 | 213 |

NMS 0.90 中相对于原配置新增保留 1819 个候选，同时丢失原候选 28 个，因此净增
1791 个。新增框全部与某个原同类候选 IoU≥0.50，但**不能据此认定全部为重复目标**。
新增的 210 个 P1 正框，在锁定原 positive 匹配、只匹配剩余 GT 后，新增 9 个独立
匹配，均为 small；新增匹配/新增框为 4.29%。独立重匹配的总增量为 8，与锁定
基线的 9 不同，反映匹配竞争；二者不混用。

进一步用不依赖 GT 的保守规则排除“与原正框同类 IoU≥0.70”的新增正候选后，
仅余 2 个框、新增 1 个 small 匹配。该过滤可能损失拥挤场景中的不同目标，因此
同时保留未过滤的 210/9 统计，不以过滤后的结果代替候选本身的恢复能力。
两组都没有达到继续条件；没有启动学生训练或生成训练伪标签。

原被排除的 39 个 tile 全候选由 137 增至 330，GT 匹配仍为 9、small 匹配仍为 5，
三组正框均为 0。这些结果不计入原入训范围的增益。

## 成本、版本与边界

同一进程 warmup 约 2.66 秒后，三组各 128 tile 的推理及候选序列化分别为
1.83、1.52、1.63 秒；PyTorch 峰值 allocated 显存分别约 979、1062、1212 MiB。
这些是单次短测，包含运行波动，不据此声称 NMS 放宽更快；显存也不是整卡占用。

初版分析将“与任意原候选重叠”直接排除，得到的增量口径过于保守。原始预测、
源码快照和 manifest 保留于 `outputs/candidate_retention_128_20261030/`；最终
v2 区分坐标相同的原预测、原正框重叠过滤和未过滤的独立恢复匹配，复用原推理，
没有追加 GPU 实验。修订来源通过 manifest 和 SHA256 关联，不能把修订当作第二个
独立样本或预先固定的过滤设计。

本结果限于一个小样本、固定教师与 split、conf≥0.05；不能外推为全量候选不存在
缺口，不能解释低于下限的预测，也不是学生 mAP、官方 AP_small 或跨 split 证据。
NMS 0.90 时有一个 tile 达到 500，未测试同时放宽 NMS 和 max-det 的组合。
当前负面信号不足以支持为此追加全量推理或训练。

## 复现与后续安排

在已有 `yolo` 环境、仓库根目录运行：

```powershell
python scripts/audit_candidate_retention.py --check
```

只重放全部 128 tile 的保存预测并核对输入、输出及原推理来源，不训练或推理。
新环境首次生成可用 `python scripts/audit_candidate_retention.py`，输出目录必须
不存在；本机已有产物时保留它们，不重复运行首次生成命令。复用旧推理生成 v2 的
命令为 `python scripts/audit_candidate_retention.py --reuse-inference`，同样拒绝覆盖。

当前执行范围已按用户授权更新：有足够信号时可自主进行至多 30 epoch 的有界训练，
启动时创建临时进度心跳，仅在完成、失败或需要处理时通知，结束后清理；每轮修改
中文提交。原有“用户自行启动训练”的安排仅保留为历史记录。本轮没有过线，
因此没有训练、没有创建无任务可观察的定时器，也没有启动更长训练。
后续优先整合正负证据与论文边界，软权重正式消融、B0、B1 重复和正式矩阵继续作为
待补缺口，不因本次检查失败自动扩训。
