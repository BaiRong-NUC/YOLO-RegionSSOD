## YOLC 为什么要挑地方放大？

想象一张航拍图里大半是空地，路口却挤着一排小车。YOLC 先看一遍整图，根据检测热图挑出最多两块密集区域，把这些地方放大再看一次。小车在第二次输入里占的像素更多，局部检测框随后放回原图。用同一份权重，本机测到小目标 AP 从 27.83 升到 30.64，小目标平均召回率也提高了 4.63 点。额外看这两块需要时间，首轮平均每张从 166 毫秒增至 344 毫秒。这个结果衡量的是局部放大相对 YOLC 自身整图检测的收益。[本机评测明细](yolc/README.md#本机对照)

## SAHI 为什么能把航拍小目标看得更准？

假设一张航拍图宽 1920 像素，远处一辆车只有 12 像素宽。普通做法把整张图缩到 640 像素宽，让 YOLO 看一次。这时车只剩 4 像素宽，很容易和路面上的斑点混在一起。SAHI 直接从原图裁出 640×640 的小块，交给同一个 YOLO 逐块看。这辆车在小块里仍有 12 像素宽，模型能多看到一些车身轮廓。相邻小块重叠 25%，刚好落在边缘的车有机会在隔壁那块里完整出现。模型也看一次整图，最后把各块和整图上框出的车对回原图，去掉重复框。

**本机两次对照都测到了精度收益。** 我们用两个训练种子得到的 YOLO11s 权重，在同样的 548 张 VisDrone 验证图上逐一比较。每次都固定权重，只换看图方式。加上切片后，第一份权重的小目标 AP 从 6.77 升到 18.65（+11.88 点），第二份从 6.90 升到 18.43（+11.53 点）。两份模型训练时都看过裁片，常规整图训练的模型能提高多少还待验证。

**看得更细也花了更多时间。** 普通做法每张图跑一次 YOLO，切片后平均跑 6.19 次，还要把各块的框合起来。在本机当前实现上，处理完一张原图的平均耗时达到整图推理的 16.61～20.27 倍。[本机评测明细](sahi/README.md#本机结论)

每篇论文在 `docs/reproduce/<论文简称>/README.md` 记录评测协议和论文报告值。判断收益时，以本机相同数据、尺寸和评测入口下的基线为对照，逐训练种子报告方法与基线的差值；固定权重的重复推理用于核验评测重复性。所有复现卡直接预览同目录的基线和方法两张 SVG，两图沿用相同的画布、层位置和编号。作者代码、适配代码和绘图脚本位于 `reproduce/<论文简称>/`。
