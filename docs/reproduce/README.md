# 论文复现结构图

| 论文 | 基线结构图 | 论文方法结构图 |
|---|---|---|
| [S³OD 双图对照](s3od/) | [SSOD baseline](s3od/ssod-baseline-architecture.svg) | [S³OD](s3od/s3od-architecture.svg) |

每复现一篇论文，在这里新建一个以论文简称命名的文件夹，放入作者基线和论文方法的两张结构图，各保存 SVG 原图和 PNG 预览。两张图沿用相同的画布、层位置和编号，便于逐处核对改动。对应的作者代码、适配代码和绘图脚本位于仓库根目录的 `reproduce/<论文简称>/`。
