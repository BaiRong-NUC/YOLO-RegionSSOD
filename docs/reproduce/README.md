# 第一步 · 论文复现结果总览

**阶段结论**　在 VisDrone 十类水平框检测上，三项推理改动在两份裁片训练的 YOLO11s 权重上都提高了小目标 AP。每项都与本机各自的基线配对。第二步已用 [SAHI 追查一辆小车](../../analyzes/reproduce/sahi/)：整图在去重前已无合格车框，切片单块检出了它。批量漏检归因待做。

| 进入诊断的线索 | val 的 AP_small 增量（点，权重 0 / 1） | 证据边界与下一步问题 |
|---|---:|---|
| [SAHI 切片](sahi/) | +11.88 / +11.53 | 同一权重多看局部，整图耗时增至 16.61～20.27 倍。哪些目标值得多看一次？ |
| [SNIP 推理尺度筛框](snip/) | +0.606 / +0.614 | 三尺度前向相同，test-dev 仍提升 +0.471 / +0.261 点。哪个视图的候选被筛掉，留下的框是否更准？ |
| [Soft-NMS 重叠降分](softnms/) | +0.154 / +0.123 | test-dev 仍提升 +0.083 / +0.079 点，总体 AP 略降。保留的框中有多少对应邻近真目标，又有多少是重复框？ |

这里验证到的是固定权重下的推理收益。独立训练的收益、组合后的增量和等耗时下的效果均待验证。其他候选的负结果、部分复现和原协议缺口一并保留如下。

## 三种推理改动分别解决什么问题？

**SAHI 改的是模型看到了多少细节。** 切片能让小车保留更多像素，当前增益最大，耗时也增加最多。**SNIP 改的是该相信哪种尺度的框。** 图像缩小时小车可能只剩几像素，同一辆车在放大视图上更清楚。本机让两组都看三种尺度，只在最后加尺寸筛选，小目标 AP 仍提高了约 0.61 点。**Soft-NMS 改的是两个框重叠以后怎么办。** 直接删框可能把旁边的真车一起删掉；改为先降分，小目标 AP 有小幅提升。实验只度量最终净收益，具体挽回了哪些车还需逐框核验。

三者的对照起点不同。SAHI 和 SNIP 都利用尺度信息，当前单项增益不能直接相加。写论文时可以把三个开关放进同一检测器，在固定数据、权重与整图耗时口径下验证组合后的实际收益。这一轮筛了多个候选，两个种子同向是描述性结果；两份历史权重也都用 val 选过 `best.pt`。跨新权重或新划分的推广要看对应的独立对照。

## 本轮配对协议

- 推理实验使用同一台 RTX 4070 Ti，Python 3.12.4、torch 2.10.0+cu128、Ultralytics 8.4.172、OpenCV 4.11、FP32；Soft-NMS 的 CPU 实现使用 Numba 0.61.2。两份 YOLO11s 权重分别来自历史裁片训练种子 0、1 的 100 轮 `best.pt`，来源与 SHA-256 见 [SAHI 卡](sahi/README.md)。此次只复用权重，研究问题已经撤销旧的 10% 标注面积约束。跨两权重的同向变化支持推理改动在这些模型上的可重复性。
- 主要划分是 VisDrone2019-DET val 全部 548 张图；SNIP 和 Soft-NMS 另在 1,610 张有标注的 test-dev 上原样评测。沿用本地 ESOD/SAHI 预处理，将 0、11 类区域涂灰，保留十类中截断等级小于 2 的框，按 COCO IoU 0.50 至 0.95 和原图小框面积统计 AP_small。该口径属于本地同协议对照。推理迁移每图最多 500 框，训练对照每图最多 300 框，跨卡绝对 AP 不作排名。
- 对推理改动，预解码图像，每臂预热 5 张（SAHI 原卡为 10 张），前后同步 GPU。计时从已解码输入到返回整图框，包含视图处理、前向、合并、回传，不含磁盘读取和精度统计。种子 0 先基线后方法，种子 1 相反。单轮毫秒数只报告观测值，微小差别不支持稳定提速。
- 训练初筛从 6,471 张标准训练图按文件名排序，用 `random.Random(2026)` 抽同一组 64 张，种子 0、1 分别独立训练 30 轮。两臂使用相同图像、初始化来源、预算与完整 548 图评测。小样本结果只回答这个预算下的问题。原始指标、日志和权重位于各篇本机 `local/`，每张卡记录可重跑入口。各论文 PDF 已归入 Zotero 项目下同名子分类。

## YOLC 为什么要挑地方放大？

想象一张航拍图里大半是空地，路口却挤着一排小车。YOLC 先看一遍整图，根据检测热图挑出最多两块密集区域，把这些地方放大再看一次。小车在第二次输入里占的像素更多，局部检测框随后放回原图。用同一份权重，本机测到小目标 AP 从 27.83 升到 30.64，小目标平均召回率也提高了 4.63 点。额外看这两块需要时间，首轮平均每张从 166 毫秒增至 344 毫秒。这个结果衡量的是局部放大相对 YOLC 自身整图检测的收益。[本机评测明细](yolc/README.md#本机对照)

## SAHI 为什么能把航拍小目标看得更准？

假设一张航拍图宽 1920 像素，远处一辆车只有 12 像素宽。普通做法把整张图缩到 640 像素宽，让 YOLO 看一次。这时车只剩 4 像素宽，很容易和路面上的斑点混在一起。SAHI 直接从原图裁出 640×640 的小块，交给同一个 YOLO 逐块看。这辆车在小块里仍有 12 像素宽，模型能多看到一些车身轮廓。相邻小块重叠 25%，刚好落在边缘的车有机会在隔壁那块里完整出现。模型也看一次整图，最后把各块和整图上框出的车对回原图，去掉重复框。

**本机两次对照都测到了精度收益。** 我们用两个训练种子得到的 YOLO11s 权重，在同样的 548 张 VisDrone 验证图上逐一比较。每次都固定权重，只换看图方式。加上切片后，第一份权重的小目标 AP 从 6.77 升到 18.65（+11.88 点），第二份从 6.90 升到 18.43（+11.53 点）。两份模型训练时都看过裁片，常规整图训练的模型能提高多少还待验证。

**看得更细也花了更多时间。** 普通做法每张图跑一次 YOLO，切片后平均跑 6.19 次，还要把各块的框合起来。在本机当前实现上，处理完一张原图的平均耗时达到整图推理的 16.61～20.27 倍。[本机评测明细](sahi/README.md#本机结论)
